# つぎつぎクイズの答えと別名

**この表は `node tools/dump-list-topics.js` が作る。**手で直さない——
直すのは `public/js/quiz-bank.js` の `LIST_TOPICS` で、走らせ直すとここが揃う。

## 形

    { topic, tier, answers:[正本…], alias:{ 別名: 正本, … } }

- **`answers` は「別々の答えは何か」の正本。**数え方（目標数）がここに依存する
- **`alias` は同じ答えの別の言い方。**`answers` に素で足すと、
  同じ答えが2回得点する（「札幌市」のあとに「札幌」が通る）
- 判定は `judgeListAnswer` が**当たった正本**で重複を見る

## なぜ別名が要ったか（指示55の棚卸し）

`normalize` はカタカナ／小書き／記号・長音・空白しか吸収せず、**漢字も接尾辞も触らない**。
そのため **11お題すべてで「正しいのに弾かれる」**が起きていた。
**罰は減点ではなく退場**（`quiz-room.js` の脱落形式）——
つまり「リコーダー」と正しく答えた子が、その一言でゲームから外れていた。
