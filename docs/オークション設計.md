# オークションバトル 設計メモ（第31弾・作り直し）

**1人1台・部屋が必須**です。遊び方は2つあります。

| 遊び方 | ひとことで |
|---|---|
| 🔨 せり上げ式 | みんなの前で値が吊り上がっていく。誰かが値をつけるたびに締め切りが延びる |
| ✉️ 秘密入札 | それぞれこっそり金額を決めて、締め切りで一斉に開ける |

## なぜ作り直したのか

前のオークションは、実質「AIの説明を聞いて誰が正解か当てる」に
チップの皮を被せただけで、**値をつけて競り合う駆け引きが無い**ものでした。
しかも「入札しても落札できなければ入札額がそのまま消える」ため、
当てる自信が無い人ほど賭けられず、ただの罰ゲームになっていました。

作り直しの芯は2つです。

### 1. 払うのは落札した人だけ

落札できなかった人は**何も失いません。** これで「いくらまでなら出せるか」を
素直に考えられるようになります。負けた人の収支に触る計算は、そもそも作っていません
（`tests/auction-logic.js`「落札できなかった人は、何も失わない」で見張っています）。

**強制最低入札額（順位が上の人ほど多く賭けさせる足枷）は廃止しました。**
落札しなければ何も起きないので、最低額を強制しても足枷になりません。

### 2. 品物の一言だけでは、価値が分からない

**同じ一言を、必ず2つ以上の価値階層で使い回しています。**
「古びた壺」は大当たり（三百年前の名品）でもあり、当たり（弟子の作）でもある。

価値階層ごとに別々の一言を用意すると、遊んでいるうちに
「重そうな箱＝大当たり」と覚えられ、駆け引きが消えます。
詳しくは [レビュー_オークション品物プール.md](レビュー_オークション品物プール.md)。

## 1ラウンドの流れ

```
① 品物が「謎めいた一言」だけで出る（正体は伏せる）
② アイテムを買う・使う（鑑定眼はここでヒントが出る）
③ 値をつける
④ いちばん高い人が落札して、その額を払う
⑤ 品物の正体と価値が明かされ、収支が出る
```

誰も入札しなければ、品物は流れて次のラウンドへ進みます（誰も損をしません）。

## アイテム（4種・すべて使い切り）

| アイテム | 効果 | いつ |
|---|---|---|
| 🎟 半額チケット | 落札できたら支払いが半額（端数は切り上げ） | 入札前 |
| ✖️ ダブルアップ | 落札した品物の価値が2倍（ハズレの損も2倍） | 入札前 |
| 🔍 鑑定眼 | 品物のヒントが1つもらえる | 品物提示後・入札前 |
| ↩️ 撤回権 | 締め切り前なら出し直せる（**秘密入札だけ**） | 締め切り前 |

せり上げ式は、値を上げること自体が出し直しなので、撤回権に意味がありません。
一覧を手で書き分けず、`sealedOnly` の印から導いています（落とし穴4）。

**救済は維持しています。** 2ラウンド終わった時点で、その時のチップが最下位の人へ
無料アイテムを1つ。並んでいたら全員へ、全員同じなら誰にも配りません。

## 決めごと（迷った時にここへ戻る）

- **同じ金額なら「先に出した人」が落札する。** ランダムだと「なぜ負けたのか」を
  誰にも説明できません。早い者勝ちなら、負けた人にも理由が言えます
- **半額チケットの端数は切り上げ。** 切り捨てにすると、奇数のときだけ妙に得をします
- **ダブルアップは大ハズレの損も2倍。** 当たりだけ2倍だと、ただ強いだけのアイテムです。
  「当たりを引けると読めた時だけ強い」形にしました
- **秘密入札では 0 で出せる（＝降りる）。** 要らない品物にまで値をつけさせません

## 秘密の扱い（原則4.3）

- **品物の正体・価値・階層・ヒントは、落札が決まるまでどの端末にも配りません**
  （大画面を含む）。配ったら、大画面を見ている全員に答えが渡ります
- **鑑定眼で引いたヒントは、買った本人にだけ**
- **秘密入札の金額は、締め切るまで本人にだけ。** 出したことだけは全員に見えます
- **せり上げ式の最高額は公開します。** そこが遊びの芯なので

わざと階層を漏らすと `tests/realtime-auction.js` が赤くなることを確認済みです。

## テーマ

金とえんじの「競り市」（`.app.theme-auction`）。ほとんど黒に近い背景に、
品物の一枚だけ上から光が当たります。クイズ王の「明るい舞台」に対して、
こちらは重くて静かな場所を狙いました。追加専用のスコープです。

効果音は木槌（ガベル）と落札音。**操作は何も変えていません。**

## 前の手渡し版について

作り直す前の手渡し版（モードID `auction`）は、`hidden` のまま残してあります。

- 棚には出ません
- `game` は `'auction'` のまま触っていません（IDを変えると、そのIDで残っている
  記録が迷子になります）
- 消すと、そこに付いているテストごと無くなるので残しました

**もう要らないと判断したら、`hidden:true` の行ごとモードを削るだけで済みます。**
その時は、手渡し版の画面（`scr-auction-*`）と `AUCTION_ITEMS`（保険・セーフティネット）も
一緒に消してください。
