# クイズ王カセット 設計メモ（第30弾）

4つのゲームが入っています。**4つとも1人1台・部屋が必須**です。

| ゲーム | ひとことで | 決着 |
|---|---|---|
| ⚡ クイズラッシュ | 難易度を自分で選んで、時間いっぱい解き続ける | 合計点（ラウンド制なら勝ったラウンド数） |
| 🔁 つぎつぎクイズ | 順番に1人1個ずつ、まだ出ていない答えを言う | 協力＝目標数／脱落＝最後の1人 |
| 🔎 とくとくクイズ | 問題文が1文字ずつ開く。早く押して当てるほど高得点 | 合計点 |
| 🥊 早押しトーナメント | 1対1の勝ち抜き。押した順はサーバーが決める | 優勝者 |

## なぜ4つで1セットなのか

見た目は違いますが、中身は**「得点を足す」「順番を回す」「時間で締める」「順位を出す」**の
組み合わせで、8割が同じものです。だから

- ルール層　… `public/js/quiz-logic.js` 1本（`variant` で枝分かれ）
- 進行役　　… `quiz-room.js` 1本（部屋に置く状態も `room.quiz` ひとつ）
- 遊ぶ画面　… `scr-rt-quiz` 1枚（中身を差し替える）
- 設定画面　… `scr-set-quiz` 1枚（関係する区画だけ出す）

にしてあります。**4つ別々に書くと、片方だけ直してもう片方に反映し忘れる事故が
構造的に必ず起きる**ためです（このプロジェクトでいちばん多く踏んだ壊れ方）。

新しいクイズを足す時も、ファイルを増やすのではなく `variant` を足す形にしてください。

## 出題

`public/js/quiz-bank.js` から出します。**遊んでいる最中にAIは呼びません。**
ライブ生成は失敗率が無視できず、遊んでいる途中で止まるのが一番まずいためです。

問題には難易度が付いた状態で出てきます（`questionsOf` が貼ります）。
ここを貼り忘れると、**得点がどの難易度でも1点になります**（実際にそうなりました）。
`tests/quiz-bank.js` で見張っています。

## 秘密の扱い（原則4.3）

どれも「サーバーだけが答えを知っている」形です。端末には次のものを**一度も**送りません。

- **正解の位置**（`correct`）。判定は `quiz-room.js` の中だけで行います
- **つぎつぎクイズの正解一覧**。送ったら、答えを読むだけの遊びになります
- **とくとくクイズの元の問題文**。伏せ字にしたあとの文字列だけを送ります。
  元の文を送って端末側で隠すと、通信を覗くだけで丸見えです

端末へ配るものに `correct` という名前は使いません（当たったかどうかは `hit`、
正解した数は `hits`）。こうしておくと「配ったものに `correct` が無い」ことを
テスト1行で見張れます。`tests/realtime-quiz.js` が、大画面を含む全端末が
受け取ったものを全部つないで探しています。

## 早押しの「先に押した」判定

**サーバーが受け取った時刻**で決めます（`quiz-room.js` の `buzzerBuzz`）。
2人の端末には同じ `askedAt` の問題が同時に届きます。

問題の出し方は2つから選べます。

- **読み上げる**（既定）… 端末が読み上げます。**画面には文字を出しません。**
  文字も出すと、読み上げを待たずに読んだ人が必ず勝ち、選んだ意味が消えます
- **文字で出す** … 2人の端末（と大画面）に同時に文字で出します

トーナメントの組み方は `quiz-logic.js` の `buildPairs` 1本です。
手渡し版の早押しも同じものを使っています。

## 止まらないようにしてあるところ

電波が切れた人がいても進行が止まらないよう、どの段階にも期限を置いています。
期限は `room.quiz.deadline` に入れ、`realtime.js` の500msごとの見回りが拾います
（見回りの仕組みは増やしていません）。

| ゲーム | 何で動くか |
|---|---|
| クイズラッシュ | ラウンドの制限時間 |
| つぎつぎクイズ | 1人の持ち時間・全体の制限時間 |
| とくとくクイズ | 次の1文字が出る時刻／押した人の持ち時間 |
| 早押し | 押した人の持ち時間／誰も押さないまま30秒 |

とくとくクイズは「次の1文字が開く時刻」を期限に入れることで、
**進行の仕組みを増やさずに**1文字ずつ開いていく画面を作っています。

## 決めごと（迷った時にここへ戻る）

- **とくとくクイズの得点は、待っても0にしない**（基準点の25%は残す）。
  0にすると「もう押さない方が得」になり、誰も答えなくなります
- **つぎつぎの協力形式では、間違えても終わらせない**。みんなで積み上げる遊びなので、
  1人のミスで打ち切ると成立しません。目標に届かなくても、出せた数は全員の点に残します
- **先取ポイントの候補は、ラウンド数から導く**（`winTargetsFor`）。
  3ラウンドしか遊ばないのに「7ポイント先取」だと永久に終わりません

## テーマ

金と青の「スタジオ」（`.app.theme-quiz`）。上から降りるスポットライトと、
いま出ている問題だけが光る作りです。追加専用のスコープなので、
クラスが外れれば完全に元の見た目に戻ります。

**操作は何も変えていません。見た目だけです。**
