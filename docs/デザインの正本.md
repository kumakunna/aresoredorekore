# デザインの正本

見た目・配置について、**アプリ全体で1つに決めたこと**だけを置く。
「そのゲームだけの見た目」はここに書かない（各カセットの設計書へ）。

ここに書いてあることは、可能な限り `tests/` で機械照合する。
書いただけで守られない決まりは、書いていないのと同じ。

---

## 1. 画面の四隅の使い方（第36弾 36-6）

画面に固定で浮かぶ小さな要素（設定・戻る・リアクション等）は、
**四隅にしか置かない。そして1つの隅に置けるのは1つの役割だけ。**

| 隅 | 役割 | 要素 |
|---|---|---|
| 左上 | **1つ前に戻る** | `#floatingBackBtn`（`.floating-back`） |
| 右上 | **設定と、いまの状況** | `#floatingGearBtn`（`.floating-gear`）／`#floatingStatusBtn`（`.floating-status`。⚙の左隣へ横にずらす） |
| 左下 | **リアクションを送る** | `#reactBar` |
| 右下 | **ありがとうを贈る** | `#thanksBtn` |

- **飾りを隅に置かない。** 季節の装飾のような「操作ではないもの」は、
  隅ではなく本文の中（見出しの下の帯など）に置く。
  隅は指が届く場所であり、押せないものを置くと押しに行かれる。
  第36弾より前は季節の風鈴（`#seasonDeco`）が右上に固定されていて、
  スマホ幅では設定の⚙とちょうど重なっていた。
- 右上に2つ並ぶのは、設定（⚙）と状況（👥）の組だけ。
  この2つは「同じ役割の並び」なので、横にずらして隣に置く。
- 新しく隅に置きたくなったら、**まずこの表に行を足す。**
  `tests/fixes36.js` の四隅の照合が、表に無い要素を見つけて赤くなる。

## 2. 切り替えスイッチ（トグル）の色（第36弾 36-5）

| 状態 | 色 | 理由 |
|---|---|---|
| OFF | 灰色（`--switch-off`。全テーマ共通で固定） | 「効いていない」は、どのカセットでも同じ意味 |
| ON | そのカセットのテーマ色（`--switch-on`。テーマごとに定義） | 「効いている」が、その世界の色で分かる |

- 共通の設定画面（カセットに属さない画面）の ON は、
  暖色の琥珀（`#C08A3C`）。棚も扉も生成りの紙と木の色なので、
  そこに馴染み、かつ紙の上でいちばんはっきり見える暖色を選んだ。
- **色だけで伝えない。** つまみの位置（左＝OFF／右＝ON）は従来どおり残す。
  色が見分けられなくても位置で分かる。

## 3. 時間の見せ方（第36弾 36-2）

- 残り時間を出す要素には、**必ず `data-timer` を付ける**。
- 出す・隠すの判断は**設定1か所**（`appPrefs.timerView`）で行い、
  各ゲームは「時間があるかどうか」だけを決める（出し分けの条件を書かない）。
- 3択：`always`（常に表示）／`peek`（見たい時だけ・タップで5秒だけ出る）／`hidden`（表示しない）。
