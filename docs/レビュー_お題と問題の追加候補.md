## 第6部：クイズ系の問題バンク

こちらは**ファイルとして実装済み**です（`public/js/quiz-bank.js`）。
形式・抽選・答え合わせの仕組みまで含めて、テストも通っています。

### いまの分量

| 難易度 | 問題数 | 指示の最低ライン |
|---|---|---|
| 🟢 かんたん | 25 | 50 |
| 🟡 ふつう | 20 | 50 |
| 🟠 むずかしい | 15 | 50 |
| 🔴 なにそれ | 12 | 50 |
| 🟣 むりなんだが | 10 | 50 |
| **合計** | **82** | 250（目標1000） |

つぎつぎクイズ用のお題：**11個**（都道府県・十二支・楽器・寿司ネタ・歴代総理など）

**どの階層も指示の最低50問に届いていません。** 遊びとして成立する最低限
（各階層10問以上）は確保し、テストで固定してあります。

### 選択肢を作る時に守った決まり

不正解の選択肢は、正解と**同じジャンル・同じくらいの知名度**のものにしています。
ジャンルがばらけていると、内容を知らなくても消去法で当たってしまうためです。

- ✕ 富士山 / 東京タワー / カレーライス ← 1つだけ食べ物で浮いている
- ○ 富士山 / 北岳 / 槍ヶ岳 ← どれも日本の高い山

### 追加する時の入り口

`public/js/quiz-bank.js` の `QUESTIONS` に、階層ごとに
`{ q, choices, correct }` を足すだけです。足したものは自動でテストの対象になります
（正解の位置が範囲内か・選択肢が重複していないか・問題文が他と被っていないか）。

つぎつぎクイズのお題は `LIST_TOPICS` に
`{ topic, tier, answers:[...] }` を足します。
