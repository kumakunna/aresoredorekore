A: 仕事観の教科書

本資料は仕事観カテゴリーを教科書形式で整理したもの。

# 1. プロ意識

• 仕事として品質に責任を持つ

• 完成させる能力はアイデア以上に重要

• 締切は品質の一部

# 2. アイデア発想

• 既存作品の観察

• 問題発見から企画を作る

• ユーザー体験を起点に考える

# 3. プレイヤー第一主義

• 作り手の自己満足を避ける

• ユーザーが何を感じるかを重視する

• 説明しなくても伝わる設計を目指す

# 4. 企画書

• 短く伝える

• 面白さの核を最初に示す

• 差別化要素を明確化する

# 5. 判断と取捨選択

• 全てを入れようとしない

• 重要要素へ集中する

• 完成度を優先する

# 6. 学習姿勢

• 他ジャンルも研究する

• 成功例と失敗例を分析する

• 常に改善を続ける

# 7. チームとの関わり

• 伝達コストを下げる

• 共通認識を持つ

• 感情ではなく目的で議論する

# 8. 開発哲学

• 面白さは細部の積み重ね

• 小さな不満を放置しない

• プレイヤー体験を最優先する

# 仕事観カテゴリー総括

仕事観の中心は『プレイヤーへ価値を届けるために何を優先するか』である。
アイデアだけでなく完成力、継続力、観察力、判断力が重要となる。
