C：企画・ゲームデザイン 教科書（AI参照用再構成版）

目的:
この資料はゲーム企画・ゲームデザインの原則を構造化して整理したもの。
特定動画の書き起こしではなく、ゲーム制作で利用できる知識ベースとして再構成している。

AIが参照する際の原則:
・具体例→原理→応用の順で考える
・プレイヤー体験を最優先する
・機能ではなく体験を設計する

# 第1章 ゲームデザインとは

• ゲームデザインはルール作りではなく体験設計である

• プレイヤーに何を感じてほしいかを最初に決める

• システムは体験を実現するための手段である

# 第2章 面白さの核（コア）

• 1文で説明できる核を持つ

• 複数の核を同時に追いすぎない

• 核は全要素の判断基準になる

# 第3章 プレイヤー目標

• 短期目標・中期目標・長期目標を用意する

• 次に何をするか常に理解できるようにする

• 迷子状態を避ける

# 第4章 チュートリアル

• 説明より体験で覚えさせる

• 新要素は1つずつ導入する

• 学習直後に使う機会を与える

# 第5章 報酬設計

• 成長報酬

• 収集報酬

• 物語報酬

• 達成報酬

• 社会的報酬

# 第6章 ステージ設計

• 安全地帯と危険地帯を配置する

• プレイヤーの視線を誘導する

• 学習→応用→試験の流れを作る

# 第7章 選択肢設計

• 意味のある選択を作る

• 正解を1つにしない

• プレイスタイルを認める

# 第8章 ランダム性

• 完全運任せにしない

• 実力介入の余地を残す

• 予測と驚きのバランスを取る

# 第9章 成長設計

• 数値成長

• プレイヤースキル成長

• 知識成長

• 戦略成長

# 第10章 リプレイ性

• 複数戦略

• 分岐

• ランダム要素

• 収集要素

• 高難易度挑戦

# 第11章 難易度曲線

• 最初から厳しすぎない

• 徐々に学習を要求する

• プレイヤーの成長速度を考慮する

# 第12章 失敗から学ぶ設計

• なぜ失敗したか理解できる

• 再挑戦しやすい

• 理不尽さを避ける

# 第13章 AI向け設計判断フレーム

• プレイヤーは何を目指すか

• 何が楽しいのか

• 何を学ぶのか

• 何を繰り返すのか

• 何が成長するのか

• なぜ続けるのか

# 企画・ゲームデザイン総括

優れたゲームデザインは機能の集合ではない。
プレイヤー体験を中心に据え、その体験を支えるルール、報酬、成長、学習、選択肢を一貫して設計する。
AIは新規企画を考える際、まず体験の核を定義し、その後にシステムを構築すること。
