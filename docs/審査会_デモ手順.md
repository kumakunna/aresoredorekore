指示60 B-2・B-7。**この流れは実サーバー（検証用サーバー）で、3台（進行役・QRから入る参加者・大画面）を
別々の人として動かして最後まで通してある**。スクショはその時のもの（`docs/審査会_デモ/`）。

```bash
node tools/dev-server.js
```

道具の中身は `tools/cdp.js`。**本番には向けない**）

## 1. つなぎ方

- **進行役のスマホ**：ログインしておく（部屋をつくるのにログインが要る）
- **参加者のスマホ**：何もしなくてよい。**ログインしていなくても、QRから入って準備OKまで進める**（通して確かめた）
- **大画面（TV・PC）**：アプリを開き、入口の「📺 大画面として部屋に入る」→ 部屋コードを入れる
- Wi-Fi が不安なら、**進行役のスマホのテザリング**に全員をつなぐ（下の 4節）

## 4. 困った時の対処

| 起きたこと | まずやること | それでもだめなら |
|---|---|---|
| 画面が固まった・押しても反応しない | アプリ（タブ）を閉じて開き直す。入口に「さっきの部屋にもどる」が出る | 部屋コードで入り直す（入口の「部屋に入る」） |
| Wi-Fi が切れた・つながりにくい | **進行役のスマホのテザリング**に全員をつなぎ直す。つなぎ直すと部屋に戻る | 部屋を新しくつくる |
| 部屋がおかしい（進まない・人数が合わない） | 進行役が ⚙ →「みんなを待合にもどす」 | **新しい部屋をつくる**（コードが変わるので、QRを見せ直す） |
| QRが読めない | 部屋コード（6文字）を口で伝えて、入口の「部屋に入る」に手で入れてもらう | — |
| 大画面が映らない | TV・PCで入口の「大画面として部屋に入る」→ コード | 進行役のスマホを大画面にする（⚙ →「この画面を大画面にする」） |
| 音が出ない | ⚙ → アプリの設定 → 音量 | 端末のマナーモード |
| 初めての人に「はじめてですね」が出た | 「見る」で案内、「いらない」でそのまま | — |
| 光や揺れがつらい人がいる | 最初の案内、または ⚙ → 安全に関する設定で切れる（切っても、伝えることは文字で出る） | — |
| 30本で長すぎた | 進行役が ⚙ →「みんなを待合にもどす」→「ゲームをえらぶ」で本数を減らす | — |
