# 指示66-1：見た目の土台

## 止まる所

**終わったら止めて報告。** くまくんの「OK」が出るまで 66-2 に進まない。

## 目的

新しい見た目を、古い画面をこわさずに入れる。全部の画面を撮って、同じ物差しで測れるようにする。

## 着手前

- CLAUDE.md を全部読む
- `docs/デザインの正本.md` と `docs/演出の共通部品.md` を読む
- `見本/index.html` を開いて、3つのページを全部見る（右の説明文も）
- `見本/assets/ds.css` の「(2) アプリの画面」から下が、新しい見た目の決まり（色・字・形・動き）

## やること

1. **入れ方（古い画面と混ぜない）**
   - 新しい見た目は、新しくした画面だけに効くようにする（例：画面の箱に `v2` を付けて、新しいスタイルは `.v2` の中だけに書く）
   - アプリにはもう `.btn` `.card` `.switch` などがある。見本のクラス名をそのまま入れると古い画面がこわれるので、名前は合わせなくてよい（見本の名前は意味を伝えるためのもの）
   - 色・字・動きの値は1か所にまとめる（CSSの変数）
2. **世界の色**
   - 見本の `.w-*`（上が明るく、下が暗いグラデーション）に変える。値は `見本/assets/ds.css` の「世界の色」
   - `docs/デザインの正本.md` の 1-2・1-2b を新しい値に書きかえる。どの2つも ΔE2000 ≥ 10.8（上・下・まん中の3か所で測る）。字は上でも下でも 7.8 以上、薄い字は 6.7 以上
   - `tests/design-tokens.js` を先に新しい値で赤にしてから直す
3. **書体**：M PLUS 1（日本語）と League Spartan（英字・大きい数字）。数字は1桁ずつ同じ幅の箱に入れて、数が変わっても横にずれないようにする
4. **動き**
   - 押した時 0.15秒、切りかえ 0.25秒、見せ場 0.75秒。順位が動く時だけ 0.4秒
   - 演出の設定（普通 1・速い 0.5・なし）を全部の動きにかける。3・2・1 は設定でも速くしない
5. **共通の部品**（見本で見られる物）
   - 下の帯（すりガラス・上に線と矢印）、のこり時間、帯の上から出る知らせ
   - 下から出るシート（低い・9割）、まん中の確認、ルールの札（いつも3つ）
   - 名前の札、ゲームの印、TVの帯・QR・名前の札
6. **撮って測る仕組み**
   - 全部の対象画面を、スマホ 390×844 と 375×667、TV 1920×1080 で撮れるようにする
   - やり方は任せる（見本データで画面だけ出す、または Playwright で本物の流れを動かす）。見本データの入口を作るなら、本番では開けないようにする
   - `tools/check.js` を、撮る時に全部の画面にかける。使い方はファイルの頭に書いてある（帯などのセレクタは、アプリに合わせて渡す）
7. **試しに1組だけ入れかえる**：文化祭の「待合」のスマホとTV（`見本/festival.html` の F3）
8. **決まりを書く**：`docs/デザインの正本.md` に、何を何に変えたか、古い決まりのどれが終わったかを書く

## 全部の画面の決まり（2026-10-23 のくまくんの指摘から）

- **中心**
  - 丸いボタンの中の絵、四角の中のアイコン、ゲームの印やロゴは、描かれている所の中心を入れ物の中心に合わせる（`check.js` が測る）
  - 見本でずれていた原因は「アイコンの箱（1em）と中の絵（20px）の大きさがちがう」だった。同じことをしない
  - 歯車は円の中心に、今より少し大きく（見本は 24px）
- **字の高さ**：M PLUS 1 は箱の中で少し下に見える。1か所ずつずらさず、全体の決まりで直す（目で見て上下がそろうこと）
- **ルールの番号**（1・2・3）は、今より少し右（3px くらい）
- **重ならない**
  - 箱どうし、箱と線（見出しの下の線・下の帯の線）を重ねない
  - 線と箱のあいだには、少しすき間を空ける（12px 以上）
- **改行**（全部の画面）
  1. 1行に入るなら1行
  2. 入らないなら、意味の切れ目（文節）で2行にする
     - ×「出題者がお題を、言／葉だけで説明する」
     - ○「出題者がお題を／言葉だけで説明する」
  3. 1〜2文字だけの行は作らない。そうなりそうなら、字を少し小さくするか、「、」を消すか、言い方を短くする
  4. 数字と単位を離さない（×「8人／まで」）
  - やり方
    - 日本語の文字は `word-break: keep-all; overflow-wrap: anywhere; line-break: strict` にして、折ってよい所だけで折る
    - 決まった文は「、」か `<wbr>` で切れ目を入れる
    - クイズの問題など長い文は、BudouX（Google、npm の `budoux`、Apache-2.0）で文節に切れ目を入れる
    - 名前など1行に入れたい字は、入らない時だけ少し小さくする（7割まで）
- **のこり時間**：5秒以下の時（赤い札に白い数字）と同じ大きさの箱を、ふだんから取っておく。切りかわっても字が動かない
- **縦の英字「ATSUMARE AREKORE.」**
  - 画面の右端に置き、180度回す（字の底が外を向く）
  - どの色の画面でも、目をこらせば読めるくらいの明るさにする（見本は `mix-blend-mode: difference` で灰色に見せている）
  - 画面いっぱいの塗りの上でも消えない
  - TVは端ぴったりにせず、少し内側に置く（TVによっては、ふちが切れて映る）
- **ふちのもれ**：画面いっぱいの塗りは、ふちまで少しはみ出して塗る（見本では、下に1〜2px うしろの色がもれていた）
