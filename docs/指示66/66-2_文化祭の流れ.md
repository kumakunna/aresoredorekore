# 指示66-2：文化祭の流れ（投票ループ）

## 止まる所

- **終わったら止めて報告。** くまくんが本物のスマホとTVで1回遊ぶまで、66-3 に進まない
- 勝ち負け・公平さ・秘密・お金、名前や感想の記録の扱いで迷ったら、そこで止める

## 目的

文化祭（11/14、知らない人も含めて60人以上）で使う「投票ループ」を新しい画面にして、人がいなくても回るようにする。

## 着手前

- 今のコードで、投票ループのどこまでがあるかを確かめる。報告の最初に一覧で書く（ある・ない・一部）
- `見本/festival.html` の F1〜F14 を全部見る（右の説明文が仕様）
- 00 の「見本どおりにしない所」を読む

## 決まり（見本の説明に加えて）

- 部屋は16人まで
- 投票：00 の 1・2（外れない・票の数を出さない）
- 準備OK：2回つづけて押さなかった人は、席を空ける
- 挑戦中の色に、黄緑を使わない（クリアしたように見えるため）
- 文化祭の棚から、あれそれどれこれ・オークションを外す
- むずかしさ：00 の 3。それぞれに一言の説明を付ける（例：やさしい＝はじめての人向け）。選ぶまで押せないボタンには「むずかしさを えらんでね」と出す
- いる人の一覧：00 の 4
- 感想：00 の 5。自由文は、くまくんと先生だけが見る。1か月でサーバーから消す
- 名前：8文字まで。規制には、数字の語呂（810 など）も入れる。入力欄に「ニックネームでOK。本名は出さないでね」と出す
- 名前の記録
  - 入力された名前と、規制ではじいた名前を、1か月だけサーバーに残す
  - 見られるのは、くまくんだけ（係の画面とは別の、ログインが要る所）
  - 1か月たったら自動で消す
  - 名前の入力画面に「不適切な言葉の対策のため、入力した名前を1か月記録します」と出す
- 爆発の演出は指示65でやる。ここでは今のままでよい
