# 指示66-3：ふだんの画面（入口・部屋・ゲームをえらぶ）

## 止まる所

- **終わったら報告。** カセットごとの遊ぶ画面は、このあと別の指示なので、ここでは手を付けない
- 00 の「止まって報告する所」と同じことが出たら、そこで止める

## 目的

友だちと集まって遊ぶ時の、入口から「ゲームを決める」までを新しい画面にする。文化祭の日に、来た人が文化祭の回し方とふだんの回し方の両方をさわっても、古い画面が出ないようにする。

## 着手前

- `見本/entry.html`（E1〜E5）を見る
- `見本/select.html` の「決定」「S4〜S6」を見る。その下の案A・案B・案Cは検討の記録なので、作らない

## 入口と部屋（見本 E1〜E5）

- **E1 入口**：「部屋をつくる」「部屋に入る」「1台で遊ぶ」の3つだけ。ログインと設定は右上の⚙の中
- **E2 部屋に入る**
  - コードは6文字。ボタンに「あと何文字か」を出し、そろったら「入る」に変わる
  - QRで来た人は、コードを飛ばして名前から
  - 名前は8文字まで。前に使った名前が、最初から入っている
- **E3 部屋をつくった時**
  - 進行役のスマホは「コード」「TVに映す」「ゲームをえらぶ」の3つ。人を外すのは、札を長押し
  - TVはQRが主役で、コードは下の帯
  - だれかが入ると、スマホとTVの両方で札がポンと増える
- **E4 参加者の待合**：自分の札を上に大きく。着替えは文化祭と同じシート
- **E5 遊び終わった後**
  - つぎを決めるのは進行役だけ（もう一回／ほかのゲームにする／部屋をとじる）
  - 「部屋をとじる」は、押した後に確認を出す（全員が外に出るため）
  - 参加者は、結果を見たまま待つ

## ゲームをえらぶ（見本 select.html の「決定」）

- **スマホ（進行役）**
  - 一覧：分類ごとに札が縦にならぶ。上のチップで、その分類へ飛ぶ。札には印・名前・ひとこと・人数・遊び方
  - いまの人数で遊べない札は消さない。点線でうすくして、理由を出す（「8人まで（いま10人）」）
  - 札を押すと、そのゲームのページになる。画面いっぱいがそのゲームの色で、印・名前・ひとこと・ルール3つが出る。押した印から色が丸く広がる（0.25秒）
  - ページは指で左右に送れる（はなした所で止まる、0.25秒）。順番は一覧と同じで、遊べないゲームもとばさない。下の点は、遊べないページだけ白ぬきの輪
  - 左上の ‹ で一覧へ。一覧は、さっき見ていたゲームの所に戻る
  - 下のボタンは「このゲームにする」。遊べない時は、ボタンの所に理由を出す
- **TV**
  - 選んでいる間は変えない。QR・入った人の名前・部屋のコード・進行役を出しておく（16人の時は、名前の札を少し低くして3列×6段）
  - 進行役が見ているゲームは、出さない
- **決めた時**（見本 S6）
  - 全員のスマホとTVに、同じカードを出す（1.5秒）
  - 動きの順：そのゲームの色が斜めに広がる → 印 → 名前 → 線 → だれがえらんだか
  - そのあと、そのゲームのルールと準備OKへ
- **えらんだ後**（見本 S4・S5）：カセットの中のゲームをえらぶ、モード、ログインしていない時、1台で遊ぶゲームの時
