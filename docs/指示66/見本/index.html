あつまれ、あれこれ　新しい画面案

大画面（TV）とスマホの新しい画面案です。入口と部屋、ゲームをえらぶ画面、文化祭の流れ。カセットごとの遊ぶ画面は、本物のアプリで作ります。

見られるページ PAGES

ゲームをえらぶ決まった形（一覧 → 1本ずつのページ、TVは変えない）。えらんだ後と「決めた時」の演出、検討した3案も 文化祭の流れ光と揺れの確認 → 入る → 待合 → 投票 → 決定 → ルール → 3・2・1 → クイズ解除 → 結果 → 感想、係の画面 入口と部屋入口、部屋に入る（コード・名前）、部屋をつくった時のスマホとTV、待合、遊び終わった後
このあとカセットごとの遊ぶ画面は、見本ではなく本物のアプリで作ります（指示66）

見方 HOW TO

  • 上の「演出」で 普通・速い・なし を切り替えられます（なし＝最後の形だけ）
  • 「スマホ 小さい」で 375×667 の小さい画面でも見られます。「TVの安全な枠」で、TVのふちで切れるかもしれない所が赤く出ます
  • 画面の下の「もう一度」で動きをもう一度、「大きく」で本物に近い大きさで見られます
