# 指示68-0a：材料を集める（Claude（チャット）がほしいデータ）

## 止まる所（先に読む）

- **アプリの中身（`public/`・サーバー）は変えない。** 撮って測るだけ。撮る道具に小さな足し（引数など）が要る時だけ `tools/` を変えてよい
- **終わったら止めて報告。** くまくんが、この材料を Claude（チャット）に渡す。68-0b には、くまくんの「次へ」で進む
- 1つの手順が2回失敗したら、そこは飛ばして「できなかった・理由」を書いて次へ
- push しない（写真は git に入れない置き場に置く。道具を変えた時は、68-0b のコミットに入れる）
- 目安は1〜2時間。超えそうなら M1〜M5 を先にして、残りは「やっていない」と書く
- 測る道具は1本ずつ回す（並べて回すと測りがずれる・落とし穴11）

## なぜ

Claude（チャット）は 66 の画面を全部見た（`docs/監査_66の画面_3人の目.md`）。でも、まだ見られていない物がある。

- 文字「大」の 66-3 の画面（いまある文字「大」の写真は 66-2 の時の物だけ）
- 動きが終わった形（決定のカードなど、動きの途中で写っている写真がある）
- 古い見た目のままの画面（ルールと準備OK・各ゲームの遊ぶ画面・⚙ から開く画面）
- 本番に近い条件（長いアドレス・遅いネット）

これがそろうと、文化祭までに直す物を、もれなく決められる。

`docs/監査_指示66の画像/材料68/`（git に入れない置き場の中）。最後に `材料68/できた.md` を書く。
