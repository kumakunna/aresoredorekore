# 指示68-1：2.0 の土台

## 止まる所

- **終わったら止めて報告。** 68-2 に進まない
- 実物解除を消す時、ほかのゲームも使っている物が見つかったら、それは消さずに止めて報告

## 目的

2.0 を始める前に、棚を「門を通った物だけ」にする。版の番号を入れる。門を通る前の物を、あそびテストで遊べるようにする。問題を増やせる形にする。

## やること

### 1. 版の表記：v2.00（くまくんの決定）

- 版は1か所に置く（例：`public/js/version.js`）。サーバーと画面の両方が、そこから読む。いまの版は **v2.00**
- 出す所：⚙設定のいちばん下（小さく「あつまれ、あれこれ v2.00」）と、係の画面。TV には出さない
- 感想（★）とエラーの記録に、その時の版を残す
- **push のたびに 0.01 上げる**（v2.01、v2.02…）。上げるのは、push するコミットの中で。報告に新しい版を書く
- 版が変わったのに古い画面のままの端末（開きっぱなしのスマホ・TV）は、**待合にいる時だけ**読み込み直す。遊んでいる途中は読み込み直さない

### 2. 棚を減らす（くまくんの決定）

**ふだんの棚**に出すのは、次の3本だけ。ほかは `hidden` にする（コードは消さない。棚にも「じゅんび中」の数にも出さない）

- 爆弾解除（クイズ解除）・あれそれどれこれ・人狼ゲーム
- 2.0 で作る物（みんなと同じ・ぴったり10秒・そろえて発射・クイズ王2.0・ロシアンカード2.0）は、棚に出す門を通ってから出す
- 下ろす物：オークション・すごろく・ハッタリケース（もと False or True）・進化じゃんけん・いまのクイズ王・いまのロシアンカード

**文化祭の棚**（`fes-room.js` の `FES_GAMES`）：はじめは **クイズ解除の協力版だけ**。2.0 の物は、門を通ったら足す

- 候補が1つの時は、投票を飛ばしてそのゲームに決める（決定のカードは出す）。2つの時は2択
- 候補が4つ以上ある時は、3つ出す。選び方：その人数で遊べる物 → 前の回に遊んだ物をのぞく → 出ていない回が長い順。その日の最初の回は、クイズ解除を必ず入れる（遊べる人数の時）
- 「13人以上は進化じゃんけんだけ」の決まりは消す。代わりに、その人数で遊べる物を出す。遊べる物が無い時は、いちばん多く入れる物を出し、準備OK を押した順に入る（今と同じ形）

### 3. テスト中の札

門を通る前の物を、あそびテストで遊べるようにする。

- くまくん（`FES_OWNER`）のアカウントでログインした時だけ、ふだんの棚のいちばん後ろに「テスト中」の札で出る（ふつうの部屋で遊べる）
- 文化祭の部屋では、係の画面に「テスト中のゲームも候補に入れる」のスイッチ（はじめは切。くまくんのアカウントの時だけ出す）
- ほかの人には、どこにも出ない

### 4. 実物解除を消す（くまくんの決定）

- 爆弾解除カセットの「実物解除」を、コードごと消す（`defuse-room.js`・`public/js/defuse-logic.js`・その画面・設定・テスト・`GAME_DRIVERS` の登録など）
- 消す前に、実物解除だけが使っている物の一覧を作り、報告に書く（`grep` の結果）。**ほかのゲームも使っている物は消さない**
- 爆弾解除カセットの中はクイズ解除だけになるので、ゲームをえらぶ所は飛ばす（棚の決まり「中身が1つの階層は飛ばす」）
- docs も直す
  - `爆弾解除設計.md` の実物解除の節は、「2026-10-24、くまくんの決定で削除。理由：傾きセンサーが一部のスマホで動かず、棚から下ろしていた」と短く残して、中身は消す
  - `切り出した宿題.md` の16は閉じる
  - CLAUDE.md・`あつまれあれこれ_棚全体の構想.md` の記述も合わせる（落とし穴33：表示している約束は実装より長生きする）
- 古い記録（`rounds[].mode` などに残った実物解除の ID）があっても、記録の画面がこわれないようにする

### 5. 名前を変える：False or True → ハッタリケース（くまくんの決定）

- 画面・ルール文・称号・記録の表示名を「ハッタリケース」にする。ID は変えない（変えるなら `LEGACY_MODE_IDS` に1行足す）
- 棚には出さない（チャンピオンシップへ移る予定）

### 6. 問題の形を広げる（68-5 と 68-Q の準備）

- 問題の箱に「数字で答える問題」を足せる形にする：問題文・答えの数・単位・出典（`source`）・難しさ
- 「表から作る問題」の道具を作る：表（例：都道府県の人口）1つと出典1つから、「どっちが上？」と「数字ちかい方」の問題を作る
  - 表は `data/` などに置き、出典は表ごとに1つ
  - **表を出典で確かめたら、その表から作った問題は、1問ずつ確かめ直さなくてよい**
- クイズ解除とクイズ王は、今と同じ箱から出す（箱を2つにしない）
- 検査：数字の問題にも出典と単位があること・同じ問題が2つないこと

### 7. CLAUDE.md に「質問の形」を足す

```
## 質問の形
聞きたいことは番号つきで「1. 質問／案A・案B／おすすめ：案A（理由）」。表にしない。
```
