# 指示68-2：クイズ解除 2.0（終わりの演出・TV の舞台・司会の声・16人まで・効果音の入れかえ）

## 止まる所

- **終わったら止めて報告。** 68-3 に進まない
- 16人まで遊べるようにする所で、コードの数とライフの決め方が計算で決まらない時は、止めて案を出す

## 目的

いちばん面白いクイズ解除を、もっと強くする。**ルールは変えない**（人数の上限と、それに合わせたコード・ライフの数をのぞく）。旧指示65（爆発の演出：光と音を分ける）は、ここでやる。

## やること

### 1. 終わりの演出（旧指示65）

**解除成功**
- TV：最後のコードが切れる → 0.75秒の「ため」（心拍が止まる・音が消える）→ 爆弾の光が消えて「解除」→ 入った全員の名前を大きく（協力なので全員）→ 小さな粒（点滅はしない）→ 声「解除成功！」（v24）
- スマホ：「解除！」と自分の名前だけ。音は鳴らさない。Android は短い振動1回

**爆発**
- 「演出 → 結果」の順（04の反省：演出と結果の字を重ねない）
- TV：心拍が止まる → 0.75秒の「ため」→ 爆発（音と光。画面全体の明るさが変わるのは1回だけ・揺れは0.2秒を1回）→ 煙が晴れて、静かに結果「あと◯本だった」
- スマホ：静かに「ばくはつ…」。Android は長めの振動1回

**光と音を分ける**
- 演出の設定で「光」（明るさの変化・揺れ・粒）を切っても、音と振動は残る
- 「音」を切っても、光は残る
- どちらも、どの端末でも切れる

**のこり1本・ライフ1**
- のこり1本：TV でそのコードを大きく。心拍の音を少し大きく。声「あと1本！」（v25）
- ライフが1になった時：声「ラストチャンス！」（v26）

### 2. TV の舞台

- 盤を大きく（TV の主役）
- だれかが正しく切ると、TV のそのコードが切れる（火花）＋小さく「〇〇が切った」
- 外した時は静かに。名前は今どおり出さない（設定の「だれが外したかを出す」の時だけ）
- 終わったあと、TV に「みんながいちばん迷った問題」を1つ出す（外した数がいちばん多いコード。同じなら、あとの物）。問題と正解だけで、だれが外したかは出さない

### 3. 司会の声の差し込み口（全部のゲームで使う）

### 4. 16人まで遊べるようにする（くまくんの決定 2026-10-24）

- いまは8人まで。文化祭で9人以上いると、クイズ解除が投票に出なくなる
- 16人まで遊べるようにする。コードの数とライフは人数で決める（例：コードは人数×3で上限50、ライフは8人まで3・9人から4）
- **数字は、作る前に計算で確かめる**（04の反省）。人数ごとに「1人あたりの問題数」「終わるまでの時間の見込み」「爆発しやすさ」を表にして報告に入れる。決まらなければ止めて案を出す
- 盤は、50本でも TV とスマホで読める形にする（今の「31本以上は1行6つ」を使う）

- ふだんの部屋のクイズ解除も、文化祭と同じ新しい画面にする（違う画面を2つ残さない。大切なこと9）
- 1台で遊ぶ（手渡し）のクイズ解除は、終わりの演出だけ同じ部品にそろえる。画面の作り直しは、このあと

### 6. 音の箱と、効果音の全部の入れかえ（くまくんの決定 2026-10-25）

今の音は、全部 index.html の中でその場で作る電子音（`beep`・`buzz` など）。これを、earshot で作った音のファイルに入れかえる。

**決まったこと**
- 効果音は**全部**入れかえる（下の表の8種類と、クイズ解除の新しい音）
- **音は TV だけで鳴らす。** スマホは「押した時の小さなコツ」1つだけ。TV が無い遊び方（1台で遊ぶ・TV をつないでいない部屋）の時だけ、スマホで TV の音を鳴らす
- **BGM は作らない。** 今ある BGM（待合・人狼の夜・オークション・手渡しの時間）と爆弾の心拍は、さわらない

**道具：earshot**
- https://github.com/Leonxlnx/earshot（MIT・v0.4）。`earshot/forge/bank.py` の音の部品（252種類。コードで作った音で、録音は使っていない）を使う。モデル（約1.1GB）は無くても部品は作れる
- アプリには入れない。`tools/sound/` に、音を作る台本（例：`make-se.py`）と「音の ID → 部品の名前・高さ・大きさ」の表を置く。**作った音は台本から何度でも作り直せる**ようにする
- 試した例（Claude チャット）：`bank.render('pluck/kalimba', pitch='E5')`。`pluck/kalimba_ring` は C3 より低い音は作れない
- earshot が入らない・動かない時は、そこで止めて報告

**音の箱**
- `public/js/sound.js` を作る。鳴らす所は全部ここを通す（`Sound.play('ok')` のように、音の ID で呼ぶ）
- ファイルは `public/sound/se/<ID>.mp3`。**入口では読み込まない。** TV の画面になった時と、スマホは「コツ」1つだけを、あとから読み込む（入口の重さを増やさない。B19 の測りで確かめる）
- AudioContext は1つを使い回す（1回ごとに作ると6個前後で音が止まる。爆弾の心拍の所に書いてある落とし穴）
- 音量は今の `sfxOut` を通す。演出の設定の「音」を切ったら鳴らない。iOS は触った時に起こす（今の作りと同じ）
- **ファイルが読めない時は、今の電子音で鳴らす**（文化祭の当日に音が消えないように）

**入れかえる音**（今の場所はすべて index.html）

| 今 | 使っている所 | 新しい音の ID | 部品の候補（決めるのは Claude Code。聞いて合わなければ変える） |
|---|---|---|---|
| beep（3・2・1・残り秒） | カウントダウン・残り時間 | `tick`・`count` | `hover_tick/*`・`click/tink` |
| beep（上がる2音） | 正解・決まった時 | `ok`・`decide` | `pluck/kalimba`（音階で上げる） |
| beep（短い1音） | 押した時のコツ | `tap`（スマホでも鳴る唯一の音） | `click/soft`・`pro_click/soft` |
| buzz | まちがい・禁止ワード | `ng` | `knock/plastic` など（低く短く。こわくしない） |
| wrongSound | まちがい・失敗 | `miss` | 同上（`ng` と分ける） |
| fanfareSound | クイズ王の正解・称号 | `fanfare` | `pluck/kalimba_ring` の3音・`logo_sting/*` |
| cheerSound | 盛り上がる場面 | `cheer` | 部品に人の声は無いので、明るい音の重ねで代える。合わなければ今の音のまま残して報告 |
| timeUpSound | 時間切れ | `timeup` | `pluck/kalimba` の下がる2音 |
| gavelSound | オークションの木槌 | `gavel` | `knock/wood`・`knock/desk` |
| soldSound | 落札 | `sold` | `knock/wood` ＋ `pop/*` |
| （新） | クイズ解除：コードを切る・火花・解除成功・爆発 | `cut`・`spark`・`defuse`・`boom` | 1節の演出に合わせて選ぶ |

- 1つの ID に2〜3本作り、鳴らすたびに変える（同じ音が続くと安っぽく聞こえる）
- 音の大きさをそろえる：earshot の `measure`（または台本の中の測り）で、最大の大きさ -1dB 以下・大きさのそろい ±2LU の中
- 安全の決まり：大きな音は爆発の1回だけ。高すぎる音・長く続く音は使わない

**くまくんが聞くための物**
- 全部の音を順番に並べた「音の見本帳」（1つの mp3 と、ID の一覧）を `docs/音の見本帳/` に置く。くまくんは 10/30 のあそびテストの前に聞く
- 「いい音か」は Claude Code には決められない（earshot も好みは判定できないと書いている）。報告では「くまくんに聞いてほしい音」を3つまで挙げる
