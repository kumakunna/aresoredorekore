# 指示68-3：新作「みんなと同じ」

## 止まる所

- **終わったら止めて報告。** 68-4 に進まない
- お題の中身で迷ったら（人を傷つけないか）、そのお題は入れずに、報告に書く

## 目的

知らない人どうしでも、しゃべらなくても盛り上がる新作。文化祭の投票と同じ形（だれにも票の数を見せずに選び、最後に開く）を、そのまま遊びにする。**2.0 の「カセットの約束 v1」で作る最初の1本。** くまくんの Notion の案「一致団結」を、協力モードとして入れる。

## 遊び方（ルールの札3枚）

1. お題に答える（3つか4つから選ぶ）
2. いちばん多い答えを選んだ人に1点
3. 5問で1回

## 流れ（1問 約20秒）

- TV とスマホにお題が出る（例：朝ごはんといえば？　ごはん／パン／食べない）
- 全員が選ぶ（10秒）。選んだら変えられない
- **開くまで、だれが何を選んだかも、何人選んだかも出さない。** TV には、選び終わった人の名前だけが光る
- 全員が選ぶか時間切れ → 声「せーの！」（v15）→ 割合の棒が0からのびる → いちばん多い答えに冠 → その答えの人の名前
- 点
  - いちばん多い答えの人に1点。同じ数で並んだら、並んだ答えの人全員に1点
  - 全員ちがう答えなら、だれも点なし（「ばらばら！」と明るく）
  - 選ばなかった人は0点（責める字は出さない）
- 5問のあと結果。称号：「いちばんみんなと同じだった人」「ひとりだけの答えをいちばん多く出した人」

## モード

- **多い方**（ふつう）：上のとおり
- **少ない方**：いちばん少ない答え（だれも選ばなかった答えはのぞく）の人に1点
- **一致団結**（協力）：全員の答えをそろえるのが目標。点は「いちばん多い答えの人数 ÷ 全員」を5問たした「そろい度」。全員がそろった問題は大きくほめる。協力なので、順位は出さない

## お題

- 置き場所は、お題だけのファイル（例：`public/js/onaji-bank.js`）。問題の箱とは分ける（正解が無いので）
- 最初の20個は、くまくんが書く（届いたら入れる）。届くまでは、Claude Code が100個の下書きを作り、`docs/みんなと同じ_お題の下書き.md` に置く。**Claude（チャット）が見て、通した物だけ本番に入れる**
- 出さないお題：体・見た目・恋愛・家族・成績・お金・宗教・政治・病気・だれか1人を選ばせる物（「この中でいちばん〇〇なのは？」は出さない）
- 出すお題：食べ物・季節・あそび・学校の行事・「もしも」など、軽い物。どれを選んでも恥ずかしくない選択肢にする
- 選択肢は3つか4つ
- 文化祭までに300個（1回5問なので60回ぶん）。同じ日に同じお題がなるべく出ないようにする

## 画面

- スマホ：お題と、大きな選択肢のボタンだけ。押したら「えらんだ」とだけ出る
- TV：お題・のこり時間・選び終わった人の名前 → 開く
- 16人でも読める形にする（名前の札を小さくするか、数だけにする）
- 見せ場：割合の棒がのびる → 冠。報告にこの1枚

## カセットの約束 v1

- このゲームを作りながら、`docs/カセットの約束.md` を書く。カセットが書くのは次だけ
  - 名前・人数・1回の長さ
  - ルールの札3枚
  - 設定
  - サーバーの決まり（状態・操作・時間切れ・終わり）
  - 見せる物の分け方（みんなに見せる物／本人にだけ送る物／TV にだけ出す物）
  - 見せ場（開く時に何をするか）
  - 結果と称号
- 部屋・名前・時計・投票からの流れ・画面の部品・演出の設定・検査は、土台が持つ
- いまの `GAME_DRIVERS` の約束（`publicView`・`privateFor`・`submitAction` など）を使う。新しい仕組みを作らない
- 文化祭の投票の部品（選ぶ・数を見せない・開く）を使い回す。写さない

## 人数

- 3〜16人。2人の時は出さない（多い方が決まらないため）
