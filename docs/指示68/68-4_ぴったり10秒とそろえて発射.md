# 指示68-4：新作「ぴったり10秒」「そろえて発射」

## 止まる所

- **終わったら止めて報告。** 68-5 に進まない
- そろえて発射で、端末ごとの時計のずれを直しても、比べる時の誤差を0.05秒より小さくできない時は、止めて、測った数を報告する（遊びがただの運になるため）

## 目的

ボタン1つだけで、知らない人どうしでもすぐ遊べる2本（くまくんの決定：「つなぎ」ではなく、ゲームとして作る）。どちらも 2〜16人・約3分。カセットの約束 v1（68-3）で作る。

## ぴったり10秒（競争）

**ルールの札**
1. 「スタート」から、心の中で10秒数える
2. 10秒だと思ったら「ストップ」
3. いちばん近い人の勝ち。5回勝負

**流れ**
- TV：声「よーい……」（v31）→「スタート！」（v08）→ 全員のスマホで時計が動き始める
- 時計は3秒で見えなくなる。そこからは心の中で数える
- **時間はスマホの中で測る。** スタートを受けたスマホが、自分の画面に時計を出した時から、ストップを押すまで。通信の遅れが入らないように
- サーバーは、ありえない値（0秒より小さい・目標＋10秒より大きい）をはねる
- ストップを押した人の画面は「ストップ！」だけ。タイムは開くまで出さない（TV にもほかの端末にも）
- 全員が押すか、目標＋10秒で締め切り（押さなかった人は記録なし。責める字は出さない）
- 開く：下の「見せ場の台本」のとおりに動かす

**見せ場の台本：ぴったり10秒の「開く」（TV 1920×1080・演出ふつう）**（Claude チャット 2026-10-26 追記）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：画面が少し暗くなり、真ん中に大きな物差し（目標の秒が真ん中の太い線。左右に ±3秒）が下からせり上がる | 音を止める |
| 0.75秒〜 | 名前の札が**上から1枚ずつ落ちてきて**、物差しの自分の秒に「トン」と刺さる。**遠い人から**、1枚0.25秒。物差しから外れる人（±3秒より遠い）は端に寄せて止める | 1枚ごとに短い音（だんだん高く） |
| 残り2人 | 物差しが**ぐっと拡大**する（±0.5秒の目盛りに）。最後の2人はゆっくり落ちる（0.5秒ずつ） | 心臓の音のような低い音 |
| 最後の1人 | 刺さった瞬間に冠。名前が画面いっぱいに大きく出て、差「+0.12秒」 | 決まった音・声 v17 か v18 |
| 0.00秒の時 | 金色の粒が画面いっぱいに広がり（点滅はしない）、「ぴったり！」の帯 | 声「ぴったり！」（v18）|

- 名前を大きく出すのはいちばん近い人だけ（決まり5）。ほかの人の札は小さいまま
- 1回の開くは、全部で5秒以内（3分で5回を回すため）
- 演出「なし」では、最後の形（物差し・札・冠）をすぐ出す

**5回の目標**：10秒 → 5秒 → 15秒 → 10秒（時計が最初から見えない）→ 20秒（点が2倍）

**点**：近い順に5・4・3・2・1点（6位から0点）。差が同じなら同じ順位。最後の回は2倍
**称号**：「ぴったりの人」（0.00秒を出した）、「体内時計の名人」（5回の差の合計がいちばん小さい）など

## そろえて発射（協力）

**ルールの札**
1. 全員で、同じ瞬間に「発射」を押す
2. そろうほど、ロケットが高く飛ぶ
3. 5回たして、今日の記録をめざす

**合図は回ごとに変える**
1. TV のカウント「3・2・1・0」の、0で押す
2. カウントが「3・2…」で消える。0だと思った時に押す
3. カウントなし。みんなで声を合わせて「せーの」で押す（アプリの声は鳴らさない。みんなの声が合図）
4. 1と同じで、速いカウント
5. ラスト：3と同じ（点が2倍）

**比べ方**
- 押した時刻は、**端末の時計のずれを直した時刻**で比べる。各端末がサーバーとの時計のずれを何回か測り（往復がいちばん短かった回を使う）、押した時刻をサーバーの時刻に直して送る
- そろい＝いちばん早い人と、いちばん遅い人の差。押さなかった人は数えない
- 全員が押して、差が0.10秒以内なら「全員そろった！」
- 押した人が半分より少ない回は、ロケットが飛ばない（やり直しはしない）

**高さ**
| 差 | 高さ | 点 |
|---|---|---|
| 0.05秒以内 | 宇宙（声「宇宙までとどいた！」v33） | 100 |
| 0.10秒以内 | 月 | 70 |
| 0.20秒以内 | 雲の上 | 40 |
| 0.40秒以内 | ビルの上 | 20 |
| それより大きい | ぽてっ（笑える落ち方。だれのせいにもしない） | 5 |

**TV**
- **だれがずれたかは出さない**（協力・大切なこと5）
- 文化祭の部屋では、その日の最高記録を TV に出す（その日だけ・部屋ごと）
- ~~押した時刻を、名前なしの点で時間の線に並べる~~（**やめる**。下の台本の「エンジンの火」に置きかえる。時間の線のグラフは、遊ぶ人には分からず、全員がそろった時ほど点が重なって白いかたまりに見えるため）

**見せ場の台本：そろえて発射の「開く」（TV 1920×1080・演出ふつう）**（Claude チャット 2026-10-26 追記・くまくんの指摘から）

カウントの間は、**地面の発射台にロケット**。後ろに町のビル、空。名前の壁はうすく。

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：全員が押す（か締め切り）→ 画面が少し暗くなり、ロケットのエンジンが小さくくすぶる | 音を止める |
| 0.75〜1.25秒 | **点火**：押した人数ぶんの「火の粒」が、**押した順と間かくのまま**（0.5秒に縮めて）ロケットの下に飛びこむ。そろっていると、粒が**1つの大きな炎**に合わさる（宇宙・月は金色）。ばらばらだと、小さい炎がぽつぽつ | 粒ごとに「ボッ」 |
| 1.25秒〜 | **発射**：ロケットは画面のまん中より少し下に止まり、**景色が下へ流れていく**。地面 → ビルを追いこす → 雲をつき抜ける → 月の横を通る → 星と銀河。高さの名前（ビルの上・雲の上・月・宇宙）は、**通りすぎる看板**として横を流れる（左の固定の目盛りは使わない） | 声「発射！」（v32）・上がっていく音 |
| 着いた高さ | 景色が止まる。着いた高さの名前が大きく（「月まで！」）。その下に小さく「差 0.04秒 ＋70点」 | 着いた音 |
| 宇宙の時 | 星がきらめく粒（点滅しない）。**全員の名前が星座のように画面に散らばって光る**（協力の成功は全員が主役）。「全員そろった！」の金の帯 | 声「宇宙までとどいた！」（v33） |
| ぽてっ | 少し浮いて、ふらふら傾き、ぽてっと落ちる。「ぽてっ」の字。だれのせいにもしない | 気の抜けた音 |
| 飛ばない回 | 煙が「プスッ」と出るだけ。静かに | 小さい音 |

- 1段（ビル・雲・月・宇宙）あたり約0.6秒。宇宙まで行っても、開くは全部で6秒以内
- 揺れ・点滅は安全の決まりの中（揺れは発射の瞬間に0.2秒を1回まで）
- スマホ：開く間は「TV を見てね」と小さなロケット。着いたら高さと点だけ
- 演出「なし」では、着いた高さの絵と字をすぐ出す
- **画面に開発のための言葉を出さない**（「押した時刻（名前は出しません）」のような説明は消す）
