# 指示68-5：クイズ王2.0（みんなで早答え・数字ちかい方）

## 止まる所

- **終わったら止めて報告。** 68-6 に進まない
- 問題が足りなくて1回の中で同じ問題が出そうな時は、止めずに 68-Q を進める。報告に、その時の数を書く

## 目的

文化祭では、遊び方を2つにしぼる（くまくんの決定）：**みんなで早答え・数字ちかい方**。TV をクイズ番組の舞台にする。

## 棚

- クイズ王カセットの中は、この2つだけにする
- 今の4つ（クイズラッシュ・つぎつぎ・とくとく・早押しトーナメント）は `hidden`。コードは消さない（新しい見た目にした時に戻す）

## みんなで早答え

**ルールの札**
1. 全員が同じ問題に、同時に答える
2. 早く正しく答えるほど、点が高い
3. 10問で1回。最後の問題は点が2倍

**流れ（1問 約20秒）**
- TV：問題が大きく出る。スマホ：問題と、3〜4つの答え（大きいボタン）
- 10秒。押したら変えられない
- 全員が答えるか時間切れ → 声「せーの！」（v15）→ TV に、答えごとの人数が開く（名前は正解の答えの所だけ出す）
- 声「正解は……」（v16・ため0.75秒）→ 正解が光る → 声「いちばん早かったのは……」（v20）→ 〇〇（1.2秒）
- 点：正解で100点＋早さの点（0秒で100点、10秒で0点。まっすぐ減る）。まちがいは0点（引かない）
- 3問ごとに順位が動く（0.4秒）。最後に1位の発表
- 難しさの並び：1〜3問目はやさしい、4〜7問目はふつう、8〜10問目はむずかしい（全員が、最初のうちに1回は当てられるように）

## 数字ちかい方

**ルールの札**
1. 答えを数字で入れる
2. いちばん近い人の勝ち
3. 5問で1回

**流れ（1問 約25秒）**
- TV：問題と単位（例：東京スカイツリーの高さは？　m）。スマホ：数字のボタン（電卓の形）と単位
- 15秒。「決定」を押したら変えられない
- 開く：TV の数直線に、全員の答えが名前つきで並ぶ（遠い人から）→ 正解が上から落ちてくる → いちばん近い人に冠 → 声「いちばん近かったのは……」（v19）
- ぴったりなら、声「ぴったり！」（v18）
- 点：近い順に5・3・1点。ぴったりは＋5点。差が同じなら同じ順位
- 数直線の目盛りは、答えの散らばりに合わせて決める。とても遠い答えは、端に「→」でまとめる（読める形を保つ）
- 問題：だれも正確には知らないが、だいたいは考えられる物（高さ・長さ・年・数・人口など）。68-1 の「表から作る問題」を使う

## TV（どちらも）

- クイズ番組の舞台にする（スポットライト・いまの問題だけ光る）。今のクイズ王の「スタジオ」を、2.0 の見た目で作り直す
- 名前は、よかった人だけ大きく出す

## 見せ場の台本（TV 1920×1080・演出ふつう）（Claude チャット 2026-10-26 追記・決まり11）

**舞台**：クイズ番組のスタジオ。暗い床に、上からスポットライトが3本。問題の札は真ん中で光り、まわりは少し暗い。名前の壁はうすく後ろに。

**みんなで早答え：1問の「開く」**（全部で6秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 答えている間 | 問題の札の下に、10秒の帯がちぢんでいく。だれかが押すたびに、札のまわりに小さな光の粒が1つともる（だれが何を押したかは出さない）。残り3秒で帯が赤い縁に | 押すたびに小さな「ピッ」・残り3秒はカチカチ |
| 0.00〜0.75秒 | **ため**：全員が押す（か時間切れ）→ 照明が落ちて、答えの札（3〜4枚）だけが並んで残る | 声「せーの！」（v15）・音を止める |
| 0.75〜1.75秒 | 答えの札の上に、**人数ぶんの小さな人形（まるい玉）がぽんぽん落ちて積み上がる**（札ごとの人数がそのまま高さ）。どれがいちばん多いか、目で分かる | 玉ごとに軽い音 |
| 1.75〜2.50秒 | 声「正解は……」でスポットライトが札の上をゆれ動き、**正解の札にカッと止まる**。正解の札が前に出て金色に。まちがいの札は暗くなる（だれかを責めない） | 声 v16・決まった音 |
| 2.50〜3.70秒 | 正解の札に積んだ玉が、**名前の札に変わって**ぱらぱら開く（正解の人だけ名前）。いちばん早かった人の名前が、札から飛び出して画面いっぱいに大きく＋「1.2秒」 | 声「いちばん早かったのは……」（v20）・ほめる音 |
| 3問ごと | 順位の行が**入れかわりながら**上下に動く（0.4秒）。上がった人の行は、一瞬光る | 入れかわりの音 |
| 最後の問題 | 「ラストは2倍！」の帯が横から入る（0.4秒） | 声 v… が無ければ音だけ |
| 1位の発表 | 照明が落ちる → ドラムロール1.5秒 → スポットライトが1人に → 名前が大きく、紙ふぶき（点滅しない） | 声 v11「おめでとう！」 |

**数字ちかい方：1問の「開く」**（全部で6秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：照明が落ち、横長の大きな数直線が下からせり上がる | 音を止める |
| 0.75秒〜 | 全員の答えの札が、**遠い答えの人から**1枚ずつ数直線に「トン」と刺さる（1枚0.2秒。とても遠い答えは端の「→」の束に入る） | 1枚ごとに音 |
| 札がそろったら | 上から**正解の旗が落ちてきて**、数直線に突き刺さる（少しはねて止まる） | 声「正解は……」（v16）・ドン |
| 旗が刺さったら | 数直線が旗のまわりに**ぐっと拡大**して、いちばん近い札に冠。名前が大きく＋「あと 12m」 | 声「いちばん近かったのは……」（v19） |
| ぴったりの時 | 旗と札が重なって、金色の粒が画面いっぱい（点滅しない） | 声「ぴったり！」（v18） |

- スマホ：答えたあとは「TV を見てね」と自分の答えだけ。開いたら自分の点だけ
- 演出「なし」では、最後の形をすぐ出す
