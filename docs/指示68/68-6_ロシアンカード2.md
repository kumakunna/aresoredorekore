# 指示68-6：ロシアンカード2.0

## 止まる所

- **終わったら止めて報告。** これが 68 の最後の部
- 「しぼってめくる」が、375×667 のスマホや古いスマホで指に付いてこない時は、止めて代わりの案を出す

## 目的

芯の「しかけ合って、めくり合う」はそのまま。**めくる瞬間を見せ場にする。** くまくんの実機テスト（10/24・Android）の指摘も直す。

- カードを選ぶ時の枠線が細すぎて、見切れている
- 爆弾を引いた時の手応えが少ない。振動も無い

## やること

1. **しぼってめくる**
   - カードの下の角を、指でゆっくり引き上げると、少しずつ中が見える。引ききると開く（途中ではなすと戻る）
   - めくっている間、相手のスマホと TV にも同じ動きが出る。相手と TV には中は見せず、角がめくれていく動きだけ
   - 指で引くのが苦手な人のために、長押し（0.75秒）でもめくれる
2. **カードの見た目**：厚みと影のあるカード。選んでいる枠は太くして、見切れないようにする（10/24 の指摘）
3. **爆弾を引いた時**：TV で爆発（68-2 の爆発の部品。強さは小さめ）。スマホは揺れ0.2秒を1回＋Android は振動。「ドカン」の手応えを出す（10/24 の指摘）。セーフの時は声「セーフ！」（v29）
4. **TV で中継**
   - 2人の盤を左右に並べる
   - 対戦がいくつもある時は、TV が「いちばんあぶない対戦」（2人の体力の合計が少ない・残りのカードが少ない）を自動で選んで大きく映す
   - 「あと1枚！」の字
5. **しかける時間も見せる**：TV に「しかけ中…」と2人の名前（声「しかけて！」v27）。両方そろったら「しかけ完了」→ 声「めくって！」（v28）
6. **最後に答え合わせ**（くまくんの決定・ルールの追加）：決着したら、2人の爆弾の場所を全部開く（声「答え合わせ！」v30）
7. **負けた人は予想に回る**（くまくんの決定・ルールの追加）：生き残り戦で負けた人は、次の対戦の勝ちを予想する（スマホで2択）。当たると称号。点や順位には入れない
8. 人数：2〜8人（今と同じ）

## 見せ場の台本（TV 1920×1080・演出ふつう）（Claude チャット 2026-10-26 追記・決まり11）

**舞台**：緑の布のテーブルを上から見た形。2人の手札（厚みと影のあるカード）が左右に並び、真ん中に2人の体力（ハート）。

| 場面 | TV で起きること | 音 |
|---|---|---|
| しかける | 2人のカードが裏向きのまま**シャッフルされるように左右にすべって**入れかわる（中は見えない）。上に「しかけ中…」と2人の名前。両方そろったら、カードがピタッと並んで「しかけ完了」 | 声「しかけて！」（v27）→ カードのすれる音 → 声「めくって！」（v28） |
| めくる手が選んだ時 | 選ばれたカードが**少し持ち上がって前に出る**（影が大きくなる）。ほかのカードは少し暗く | 小さな「スッ」 |
| しぼっている間 | めくる人の指に合わせて、TV のカードも**角が少しずつ反りあがる**（中は見せない。角の裏が見えるだけ）。カードのまわりがだんだん暗くなり、心臓の音が速くなる | 心臓の音（だんだん速く） |
| セーフ | 引ききった瞬間にカードが**くるっと表に返り**、何も無い面。カードが手元に飛んで戻り、画面がふわっと明るくなる | 声「セーフ！」（v29）・ほっとする音 |
| 爆弾 | 引ききった瞬間、**0.3秒の無音**（ため）→ カードから火花 → 爆発（68-2 の部品・強さ小さめ・光は1回・揺れ0.2秒を1回）→ 煙が晴れると、ハートが1つ割れて落ちる | ドカン・ハートの割れる音 |
| あと1枚 | 残りが1枚になると、そのカードだけが光り、「あと1枚！」の字がたたきつけられるように出る | 決まった音 |
| 決着 | 勝った人の側にスポットライト、名前が大きく。負けた人の名前は大きく出さない | 声 v11「おめでとう！」 |
| 答え合わせ | 2人の残りのカードが、**端から順にパタパタと全部表に返る**（1枚0.15秒）。爆弾のカードは赤い縁で光る | 声「答え合わせ！」（v30）・めくれる音の連続 |
| 中継（対戦がいくつもある時） | いちばんあぶない対戦に切りかわる時、**カメラが寄るように**大きくなる（0.25秒）。ほかの対戦は右下に小さく並ぶ | 切りかわりの音 |

- スマホ（めくる人）：しぼる動きと、爆弾の時の揺れ0.2秒と振動（Android）。結果の字は TV と同じ短い物だけ
- 演出「なし」では、めくった結果をすぐ出す

## 秘密（今の決まりのまま）

- しかけた場所は、しかけた本人ももう一度は見られない
- めくる前の中身は、相手にも TV にも届かない（しぼっている間も）
- 答え合わせは、決着の後だけ
