# 指示68-7：ふだんの画面の残り（設定・ログイン・扉の動き・68-0b の P2）

## 止まる所

- **終わったら止めて報告。** 68 はこれで全部
- 11/5（木）の朝に間に合わない時は、そこで止めて、できた所までを報告する（凍結の後は直しだけ）
- 設定の中身（項目・既定値・上限下限）を変えないと作れない所が出たら、止めて質問を残す

## 目的

66-3 で入口・部屋・ゲームをえらぶが新しくなった。そこから開ける残りの画面を、同じ見た目にする。文化祭の日に、だれが ⚙ を押しても古い画面が出ないようにする。**中身（何が設定できるか・ログインの流れ）は変えない。見た目だけ。**

## 着手前

- 入口（E1）の ⚙ から開ける画面を、全部一覧にする（設定・ログイン・新しく登録・ログアウト・着替え・称号・遊んだ記録 など）。今の見た目か新しい見た目かも書く
- 「扉」の動き（画面が切りかわる時の扉の演出）が、どこで出ているかを一覧にする（`grep` で「扉」や door を探す）
- 一覧を報告の最初に書く

## やること

1. **設定**
   - 今ある項目は、減らさない・足さない（演出の設定・文字サイズ・音・光と揺れ など）
   - 1画面に1つのまとまり。項目ごとに一言の説明
   - いちばん下に版の表記（68-1）
2. **ログイン・新しく登録・ログアウト**
   - 流れは変えない（部屋を作る人だけアカウントが要る・入る人は名前だけ）
   - まちがえた時の言葉はやさしく、何をすればいいかを書く
3. **扉の動き**
   - 新しい見た目の動きの決まり（押す0.15秒・切りかえ0.25秒・見せ場0.75秒）に合わせる
   - 演出「なし」では止める
4. **⚙ から開ける、ほかの画面**（着替え・称号・遊んだ記録など）
   - 一覧で「今の見た目」だった物を、新しい見た目にする
   - 時間が足りない時は、ふだんの流れで開く順（多く開く物から）にやる。残った物は報告に書く
5. 見た目の決まりは `docs/デザインの正本.md` §12 と、`docs/指示66/` の見本に合わせる。見本が無い画面は、見本の部品の組み合わせで作る
6. **68-0b の第4部（P2：C1〜C23）を直す。** C18（入口の一言）は、くまくんの答え（68-0b 第5部 Q3）が来ていればやる。来ていなければ「答え待ち」と報告に書く（入口の真ん中に何を置くかは文化祭のあと）
   - 版の表記（v2.0x）は設定のいちばん下（68-1）。新しい設定の画面でも、Twemoji の表記（CC-BY 4.0）を消さずに残す
