# 指示68-S：今ある見せ場の作り直し（決まり11）

Claude チャットが 2026-10-27 に、今ある見せ場の動画（`docs/監査_指示66の画像/film-now/`）と 68-4 の撮り直しを見た。
68-2・68-3 のころの見せ場は、**黒い画面に字が出るだけ・棒グラフが伸びるだけ**で、決まり11（見せ場は動きで見せる）に届いていない。ここで作り直す。

## 止まる所

- **10/30 の朝までに push する**（あそびテストで見るため）。間に合わない物は、下の順番の後ろから「間に合わなかった」と報告する
- 台本どおりに作れない所（部品が足りない・重くなる）は、作る前に止めて案を出す
- ルール・点・秘密の扱いは変えない。変えるのは見た目と動きと音の出し方だけ
- 終わったら止めて報告。68-0b 後半には進まない

## 順番

1. クイズ解除の「解除成功」と「爆発」
2. みんなと同じの「開く」
3. 投票の「決定」
4. 68-4 の小さな直し

## 1. クイズ解除（TV 1920×1080・演出ふつう）

**解除成功**（全部で6秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：最後のコードが切れる → ほかが暗くなり、爆弾の時計の数字が止まる（02:27 のまま） | 心拍が止まる・無音 |
| 0.75〜1.50秒 | 画面のまん中に爆弾が大きく出る。爆弾のランプが**赤 → 消える → 緑**に変わる | 「カチッ」 |
| 1.50〜3.00秒 | 爆弾のふたが**ぱかっと開いて**、紙ふぶきが上へ舞う（点滅しない）。「解除成功！」が大きく | 声「解除成功！」（v24）・ほめる音 |
| 3.00〜4.50秒 | 爆弾の中から**全員の名前が飛び出して**、「解除成功！」のまわりに集合写真のように並ぶ（全員同じ大きさ。協力なので全員が主役）。残ったライフのハートが1つずつポンと出る | 名前ごとに軽い音 |
| 4.50秒〜 | 下から結果の札が上がる：「30/30本・02:27」「みんながいちばん迷った問題」 | |

**爆発**（全部で6秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：時計が 00:00（かライフが0）→ 画面が暗くなり、爆弾だけが残る。残ったコードが少しふるえる | 心拍が止まる・無音 |
| 0.75〜1.25秒 | 爆発：明るさが変わるのは1回だけ・揺れは0.2秒を1回。輪が広がり、マンガのような破片と煙 | ドカン |
| 1.25〜3.00秒 | 煙がゆっくり晴れる。こげた盤が見えて、**切れなかったコードだけが光っている**（あと何本だったかが目で分かる） | 静か |
| 3.00秒〜 | 「あと3本だった！」が大きく、その下に「つぎはいけるかも」。迷った問題の札は小さく下に | やさしい音 |

- 今の「黒い画面に『解除』『爆発』の字」はやめる
- だれかのせいにする字・名前は出さない（今と同じ）

## 2. みんなと同じの「開く」（TV・全部で6秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：選択肢の札（3〜4枚）が横に大きく並び、まわりが暗くなる。**人数の数字はまだ出さない**（今は先に出ているので直す） | 声「せーの！」（v15）・無音 |
| 0.75〜2.25秒 | 1人1つの**玉**（その人の印の色）が、選んだ札の上へ**ぽとぽと落ちて積み上がる**。積んだ高さがそのまま人数。数字は玉が落ちるたびに1ずつ増える | 玉ごとに軽い音 |
| 2.25〜3.00秒 | いちばん高い山にスポットライトと冠 | 声「いちばん多かったのは……」（v21） |
| 3.00〜4.50秒 | 冠の山の玉が**名前の札に変わって**ぽんぽん開く（点になった人だけ大きく）。「+1点」の粒 | 声「みんなと同じ！」（v22） |
| ひとりだけの時 | その1つの玉にスポットライト、名前が大きく | 声「まさかの、ひとりだけ！」（v23） |

- 下に並べている全員の名前のチップはやめる（玉と札で見せる）

## 3. 投票の「決定」（TV・全部で5秒以内）

| 時間 | TV で起きること | 音 |
|---|---|---|
| 0.00〜0.75秒 | **ため**：候補の札（2〜3枚）が並び、照明が落ちる | 声「つぎのゲームは……」（v04） |
| 0.75〜2.50秒 | スポットライトが札から札へ**はねるように移り**、だんだんゆっくりになる（行き先は決まった物。動きは見せるだけ） | カチ・カチ・カチ…（だんだん遅く） |
| 2.50秒 | 決まった札で止まる → 札が前に飛び出して画面のまん中へ。ゲームの印がはずみ、**そのゲームの世界の色が画面に広がる** | 声「これだ！」（v05） |
| 3.00秒〜 | 小さく「5人がえらびました！」 | |
| 候補が1つの時 | 札が上から落ちてきて、「これだ！」のはんこがドンと押される | 声 v05 |

## 4. 68-4 の小さな直し

- そろえて発射：上へ流れる雲が、左上の「1/5回目　カウントの0で押す」の上を通って字を隠している。雲は字の**うしろ**を通す
- そろえて発射：宇宙で「全員そろった！」の帯が、ロケットの先にかぶっている。帯と名前を少し上に、またはロケットを少し下に
- ぴったり10秒：「ため」の暗くなる所が、画面の中の四角い箱になっている。画面全体を暗くする
- ぴったり10秒：うしろの名前の壁が、ピンクのかたまり（筆でぬったような形）に切れて見える。壁は全体に同じうすさで
