### 3. 声を全部止める（ファイルは残す）。声だけの合図は、字と効果音に置きかえる

- `sound.js` の `voiceShouldPlay` を false。TV でも鳴らさない。声のファイルは読み込まない（`preload('tv')`）。ファイルは消さない
- **声だけで合図していた所を一覧にして、報告に書く。** 合図の意味がある所は、字と効果音に置きかえる。とくに：
  - **ぴったり10秒のスタート**：TV とスマホの両方に、大きな「スタート！」の字（0.6秒）。TV ははっきりした短い効果音（いまある効果音から選ぶ）。**iPhone は Web から振動できない**（Safari は `navigator.vibrate` に対応していない）ので、振動にたよらない

  - そろえて発射の「発射！」も同じ考えで、効果音を置く
- 動画：ぴったり10秒の1回目と4回目のスタート（TV 1920×1080 とスマホ 390×844 を並べて）

### 4. 効果音が割れる

1. **ファイルの大きさをそろえる**（35個）。爆発・解除・ファンファーレ・歓声のような大きい出来事は大きく、`tap`・`tick` のような小さい合図は小さく。**どの音も、いちばん大きい所（ピーク）が −3dB を超えない**（いま `tick`・`tap`・`ng`・`gavel` は −0.3〜−1dB で、ほぼ最大）。earshot の台本で作り直しても、ffmpeg で下げてもよい
2. **`sfxOut` の先にリミッターを1つ**（`DynamicsCompressorNode`。大きすぎる音をおさえる部品）。まず threshold −6dB・knee 0・ratio 20・attack 0.003秒・release 0.25秒 くらいから（MDN の初期値は threshold −24・knee 30・ratio 12）。聞いて小さすぎる時は threshold を上げる
3. **同じ音は、同時に3つまで**（4つ目は鳴らさない）。みんなと同じの玉（16人で1.2秒に16回）と、そろえて発射の火の粒（0.5秒に16回まで）がいちばん重なる
- 確かめ：`OfflineAudioContext` で、①16人のみんなと同じの開く ②16人のそろえて発射の点火 ③クイズ解除の爆発と歓声 を、本番と同じ鳴らし方で鳴らし、出てくる音のピークを数で報告する（−1dB を超えない）

### 5. 決定を5秒に。文化祭の TV は、演出の速さを「ふつう」に決める

- `fes-room.js` の `decideMs` を 5000 に（TV の決定の演出は約3.5秒。少し遅れて受けても途中で消えない）
- 文化祭の TV では、端末に残っている演出の速さの設定（localStorage の `fxSpeed`）を使わず「ふつう」にする。ふだんの部屋は今のまま。OS の「動きを減らす」の扱いも今のまま

1. **1本ずつの出し入れ（係の画面）**：ゲームごとに「入／切」。サーバーの入れ物（SQLite）に覚えて、部屋やサーバーを作り直しても戻らない（いまは作り直すと「テスト中」が切に戻り、新作3本が投票からだまって消える）。いつも2本以上は「入」（1本だけだと、決定の演出が短くなる）。「テスト中を入れる」は、これに置きかえる

3. **スマホが TV より先に結果を出す4か所**（投票の決定・ぴったり10秒・みんなと同じ・クイズ解除）を、そろえて発射の `phoneRevealHtml` と同じ形にする：スマホは、TV の台本で同じ物が出る時刻まで待ってから出す。自分の数字・順位・+点・歓声の音も、その時刻に。TV がいない部屋は今までどおりすぐ出す。クイズ王2 も同じ形か確かめる
4. **クイズ解除の幕**：TV の幕を全部で4秒以内に（いま約5.5秒。くまくんの「幕は短く」）。爆発そのもの（輪・破片・煙）は小さくしない。文化祭の結果へ移る時間（`endGraceMs`）は、幕より0.5秒以上長く。スマホの幕も TV と同じ時刻に上げる
