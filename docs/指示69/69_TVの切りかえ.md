# 指示69：TV の切りかえ（2台の TV を、係のスマホで切りかえる）

## 止まる所（先に読む）

- **まず「一の束」だけ作る。終わったら止めて報告する**（報告と動画を Claude（チャット）が見て、二の束のやり方を変えることがある）
- **push はしない。** くまくんが OK したあと、だれも遊んでいない時だけ（push のたびに版を +0.01）
- **ゲームの中身と、文化祭の部屋の進行（`fes-room.js`・各 `*-room.js`・`realtime.js` の進行の処理）にはさわらない。** 足してよいのは、新しいファイルと、道をつなぐ数行（`server.js` に道を足す、など）だけ。さわる必要が出たら、止めて聞く
- **あそびまち（asobimachi.duckdns.org）のコードと設定にはさわらない**
- 次のことが出たら、その場で止めて質問を残す。推測で進めない
  - TV の PC の Windows の設定（音の出し先・画面の並び）を、この指示に書いた以外に変える必要がある
  - Chrome の拡張機能では、この指示のことができないと分かった
  - 11/4 に間に合わない見込みになった

## 0. この指示で使えるようになるもの（1文）

**くまくんの PC につないだ TV 2台の画面（あつまれ・メニュー・あそびまち・制作中の動画・休けい）を、係のスマホのボタンだけで、TV ごとに切りかえられる。**

対象外（この指示ではやらないこと）：
- 飲食のメニューの中身（入るかも形も未定。入れる場所とボタンだけ用意する）
- TV が1台ずつ別の PC の形（2台の PC）。今回は PC 1台に TV 2台
- 見た目の作り込み（くまくん：「見た目はどうでもいい。使いやすさだけはマジで頑張って」）

## くまくんの決め（2026-11-02）

| 項目 | 決め |
|---|---|
| 作る所 | あつまれのサーバーの中に、別のページとして作る |
| TV と PC | PC 1台（くまくんの PC・Windows・Chrome）に TV 2台。前の壁の左が TV①、右が TV② |
| 作り方 | Chrome のタブを切りかえる。TV の PC に Chrome の拡張機能を入れる（くまくんの PC なので入れられる） |

| 音 | Windows の音の出し先は1つ。**全部の音を TV① のスピーカーから出す。** TV② の画面の物で鳴らすのは、あそびまちのチャイムだけ。動画の音は、はじめ「切」（スイッチで入にできる） |
| 自動で回す | TV ごとに「自動で回す」の ON／OFF スイッチ。係が出す物のボタンを押したら、その TV の自動は OFF になる |
| 使う人 | 係だけ（今の文化祭の係のログイン：owner と staff）。あとで係を足せる |
| 期限 | **11/4 までに作る。** 11/4 の本番での試し・11/5 の学校での確認・11/6 のリハーサルで使う |

## あそびまちのモニターについて分かっていること（Claude が 11/2 に確かめた）

- `X-Frame-Options: SAMEORIGIN`・`frame-ancestors 'self'`。**ほかのページの中（iframe）には出せない。** だからタブで開く
- 最初に「押すと始まります」を1回押さないと、呼び出しのチャイムが鳴らない（ブラウザーの決まり）。F キーで全画面、M キーで音の入／切
- 呼び出しは数秒ごとにサーバーに聞きに行く作り。見えていないタブでも動く
- **URL の `key=` は合い言葉。** コード・docs・git・ログ・リモコンの画面に出さない。サーバーの `.env`（例：`TVS_ASOBI_URL`）に入れて、TV の PC の拡張機能にだけ、係のログインを通して渡す

- 係の門（`fes-routes.js` の `gate`）と、係の画面の作りを読む。リモコンは同じ門を使う

## 2. 仕様

### 2-1. 仕組みの案（おすすめの形）

- **拡張機能**（Chrome の MV3・パッケージしない形で読み込む）：置き場所はリポジトリの `tv-switcher/extension/` のような、サーバーが配らない所
- 拡張機能が Chrome のウィンドウを2つ開き、TV① と TV② の画面に1つずつ、全画面で置く（`chrome.windows`・`chrome.system.display`）
- 各ウィンドウに、出す物を1つずつタブで開いておく。**切りかえ＝見せるタブを変えるだけ。** ページは閉じない・開き直さない（あつまれのゲーム・あそびまちの呼び出し・動画は、裏でも動き続ける）
- **タブの順番を決めておく**（1 あつまれ・2 メニュー・3 あそびまち・4 動画・5 休けい）。拡張機能が止まっても、TV の PC で **Ctrl+1〜5** を押せば切りかえられる
- サーバーとのつなぎは、あつまれの Socket.IO と係のログインを使う。Chrome が拡張機能の裏の処理（service worker）を眠らせても切れない形にする（例：「休けい」のタブを、あつまれのサーバーの係のページにして、そこがサーバーとつながり、拡張機能に伝える）
- 今どの TV に何を出しているか・自動回しの設定・出す物の一覧は、サーバーの SQLite に覚える（`fes_game_switch` と同じ考え方）。サーバーを作り直しても（push しても）元にもどる

### 2-2. 画面と流れ（面ごと）

**リモコン（係のスマホ）`/tvs`**
- 係のログインが無ければ、ログインへの案内だけを出す
- 1画面だけ。上に TV①、下に TV②。**390×844 のスマホで、スクロールせずに TV① と TV② のボタンが全部見えて押せる**
- TV ごとに：
  - 今の画面の名前を大きく（例「TV①：あつまれ」）。つながりの印（● つながっている／× 切れている）と、最後に連絡があった時刻
  - 出す物のボタン（あつまれ・メニュー・あそびまち・動画・休けい）。高さ 56px 以上。今映っているボタンは色と「いま」の字（色だけに頼らない）
  - **1回押すだけで切りかわる。確かめは出さない。** ただし、その TV があつまれを映していて、文化祭の部屋がゲーム中（3-2-1・遊ぶ）の時だけ、画面の中に「いまゲーム中です。切りかえますか？［切りかえる］［やめる］」を出す（`window.confirm` は使わない）
  - 押したあと、TV から「変わった」の返事が来たら、ボタンに「変わりました」。3秒たっても来なければ「TV から返事がありません」
  - 「さっきの画面にもどす」（押しまちがえた時用）
  - 「自動で回す」の ON／OFF（二の束で中身を作る。一の束では置かなくてよい）
- 2人の係が同時に開いていても、同じ状態が出る（片方が押したら、もう片方にもすぐ出る）

**TV の PC（拡張機能）**
- 準備は、Chrome を開いて「はじめる」を1回押すだけ。押すと：
  1. ウィンドウ2つを TV① と TV② の画面に全画面で開き、タブを全部開く
  2. あそびまちの「押すと始まります」を押すように、画面で案内する（ここだけ人が押す）
  3. 「TV① と TV② を入れかえる」ボタン（左右が逆だった時用）
- PC や Chrome を開き直しても、同じ「はじめる」で前の画面にもどる
- **見えていないタブは音を消す**（`chrome.tabs.update` の `muted`）。例外は、あそびまちのチャイム。見えていなくても鳴る。鳴るのはどちらか1つのタブだけ（2回鳴らない）
- **動画**：TV の PC に置いたファイルを、くり返し、音はじめ「切」で流す。入れかえ方は、くまくんが1分で分かる形（例：決まったフォルダーに置くだけ・または「はじめる」の画面で1回えらぶだけ）。ファイルが無い時は、リモコンのボタンに「まだありません」
- **メニュー**：画像を何枚でも置ける場所を、動画と同じ仕組みで用意する。無い時は「まだありません」
- **休けい**：大きな字で「準備中です」。字は係の画面で変えられる（二の束）

**係の画面（出す物の一覧）**
- 出す物を足せる：名前・種類（URL／PC のファイル）・出せる TV（①②）・音（入／切）
- あそびまちは `.env` の URL を使う。画面には「あそびまち」としか出さない

### 2-3. 同じ物を2台で同時に出す時

あつまれのタブを2つ動かすと TV の席が2つになり、あそびまちのタブを2つ動かすとチャイムが2回鳴る。次のどちらかで、**作る前に考えて報告に書く**：
- 案1：出す物は1つずつだけ開いておき、出す TV のウィンドウへタブを移す（`chrome.tabs.move`。ページは開き直さない）
- 案2：2つ目を開くが、音を消し、あつまれは2台目の TV として入る（サーバーは2台目の TV を消さない作り）

### 2-4. 秘密の表

| もの | リモコン（係） | TV の PC の拡張機能 | 係でない人 | git・docs・ログ |
|---|---|---|---|---|
| あそびまちの URL（key 付き） | ✕（名前だけ） | ○ | ✕ | ✕ |
| 今の画面・自動回しの設定 | ○ | ○ | ✕ | ○（key 以外） |
| 切りかえの記録（だれが・いつ・何を） | ○ | ✕ | ✕ | ○ |

### 2-5. 覚える所と、もどる所

| もの | サーバーの作り直し（push） | Chrome の開き直し | 文化祭の部屋の作り直し |
|---|---|---|---|
| TV ごとの今の画面 | 残る | 残る（「はじめる」で同じ画面へ） | 残る |
| 自動回しの ON／OFF と中身 | 残る | 残る | 残る |
| 出す物の一覧 | 残る | 残る | 残る |
| あそびまちの「押すと始まります」 | — | **押し直す**（ブラウザーの決まり） | — |

### 2-6. 困った時（異常系）

- サーバーが止まった・再起動した：TV は今の画面のまま。リモコンは「サーバーにつながりません」。もどったら自分でつなぎ直す
- 拡張機能が止まった：TV は今の画面のまま。リモコンは × と最後の連絡時刻。TV の PC で Ctrl+1〜5 でも切りかえられる
- TV の PC のネットが切れた：メニューと動画は出し続ける。リモコンは ×
- 係が2人で同時に押した：あとから届いた方にそろう。両方のリモコンに同じ結果が出る
- あつまれのタブが「F5 で開き直してください」の札を出した：リモコンにも「TV①：あつまれの開き直しが要ります［開き直す］」を出す（拡張機能がそのタブだけ開き直す）

### 2-7. 文言

画面に出す字は短く、責めない言い回し。開発の言葉（タブ・拡張機能・socket など）はリモコンに出さない（決まり12）。例：「変わりました」「TV から返事がありません」「いまゲーム中です。切りかえますか？」「まだありません」

### 2-8. 演出

なし（切りかえは一瞬で。フェードなどは入れない）。

## 5. 二の束（一の束の報告のあとで作る・参考）

- **自動で回す**：TV ごとに ON／OFF。回す物と秒数をえらべる。はじめは TV② が ON（メニュー20秒 → あそびまち20秒 → 動画1回分）、TV① は OFF。係が出す物のボタンを押したら、その TV は OFF になる
- **あそびまちで呼び出しがあったら、TV② を自動であそびまちに30秒**（チャイムが鳴った瞬間を、タブの音の始まりで見つける）。そのあと元の画面か自動回しにもどる。ON／OFF 付き
- **あつまれに人が入ったら（呼び込み → 待合）、TV① を自動であつまれにもどす。** ON／OFF 付き
- 自動の切りかえは、あつまれのゲーム中にあつまれを映している TV を、決して切りかえない
- **お知らせの一言**：TV ごと（または両方）の画面の下に、字の帯を出す。どのタブの上にも出す
- 休けいの字を、係の画面で変えられる
- **切りかえの記録**：リモコンの下に、新しい順で10件（だれが・いつ・何を）
