## 2. スマホが入れない・固まった時

**画面の字で見分ける**

| 出ている字 | どうする |
|---|---|
| 「電波がとどいていないようです。つながったら、すぐもどります」 | Wi-Fi か電波を確かめる。つながれば自動でもどる。学校の Wi-Fi がだめなら、スマホの回線（Wi-Fi を切る）で開き直す |
| 「つなぎ直しています」 | 数秒待つ。自分でつなぎ直している |
| 「満員です。つぎの回をまってね」 | 「つぎの回に入る（予約する）」を押して、**画面をそのままにしておいてもらう**。席が空くと自分で入る（20秒以内） |
| 「もどってきた時に満員だったので、少し待っていてね」 | 30秒より長く切れていた人。そのまま待てば、席が空いた時に自分で入る |
| 「はじめに、光と揺れの確認」 | はじめて開いた端末。そのまま「**はじめる**」 |
| 「まもなく始まります」 | 部屋がまだ無い。係が作るのを待つ（できたら自動で進む） |

**固まった（押しても動かない・画面が変わらない）**
1. ページを読み込み直す（Safari はアドレスの横の ↻、Android の Chrome は画面を下に引っぱる）
2. 名前は覚えている。**切れても30秒は席を取ってある**。遊んでいるゲームの中にいる人は、何秒たっても・満員でも戻れる
3. だめなら、ブラウザを閉じて QR から入り直す

**画面の上が切れる・下に余白が出る（iPhone）**
- 読み込み直せば直る。あとで調べたい時だけ：そのスマホのアドレスの最後に **`#vplog`** を付けて開くと、その端末の記録（最近50件）が出る。**写真を撮っておく**（どこにも送られない）

**QR が読めない**：アドレスを打ってもらう `aresoredorekore.duckdns.org/fes`

**「しばらくしてから入れます　あと約◯分」と出る人**：係が「外す」を**長押し**した人。時間がたてば入れる。
ふつうに押した「外す」なら、名前を入れればすぐ入り直せる

## 3. TV が映らない・全画面がとれた時（TV の PC）

TV は、くまくんの PC の「**あつまれ TV**」（TV 専用の Chrome）で出す。ふだんの Chrome では「はじめる」を押せない。

| こまったこと | どうする |
|---|---|
| 全画面がとれた | 2秒待つ（拡張機能が自分で全画面にもどす）。もどらなければ、TV の「はじめる」の画面でもう一度「はじめる」 |
| 拡張機能が止まった・出す物が変わらない | TV の窓を1回押してから **Ctrl+1〜7**（1 あつまれ・2 メニュー・3 あそびまち・4 動画1・5 休けい・6 画像2・7 動画2） |
| TV の隅に「F5 で開き直してください」 | TV の窓を1回押して **F5**。開き直すと自分で部屋に入る |
| あつまれの TV に「はじめに、光と揺れの確認」 | その Chrome がはじめて（または記録を消した）。「**はじめる**」を1回押す |
| TV に何も映らない | ① TV の入力（HDMI）② Windows の「ディスプレイの設定」で画面の数と並び ③ 線を挿し直したら、TV の窓を自分で置き直す（画面が3つ以上の時、ノート PC の画面は TV にえらばない） |
| あそびまちがエラー | 30秒待つ（自分で開き直す）。直らなければ TV② の窓を押して **Ctrl+3 → F5** |
| 描くのがカクつく | Windows の「ディスプレイの設定」で TV の解像度を 1920×1080 に |
| 音が出ない・ちがう TV から出る | 音は Windows の出し先1つから出る。タスクバーのスピーカー → 出し先を **TV① の HDMI** に（Sonar を使う時は Sonar の出し先） |
| 部屋を作り直した | TV は何もしなくてよい（自分で新しい部屋に入り直す） |

切りかえは係のスマホの `/tvs`（リモコン）。**ゲーム中のあつまれの TV は、自動では切りかわらない**。

## 4. サーバーが止まった・重い時

### まず見分ける（スマホで1分）
1. **スマホの回線（Wi-Fi を切る）**で `https://aresoredorekore.duckdns.org/fes` を開く
   - 開ける → サーバーは生きている。**学校の Wi-Fi の問題**。みんなにスマホの回線で入ってもらう
   - 開けない → 2 へ
2. 同じく `https://aresoredorekore.duckdns.org/api/fes/current` を開く
   - `{"code":"…"}` か `{"code":null}` が出る → サーバーは生きている（ページだけ重い。読み込み直す）
   - 何も出ない・エラー → サーバーかネットの名前（DuckDNS）の問題。3 へ

### PC からサーバーを見る（読むだけ）
つなぎ方は `docs/障害と復旧_2026-09.md`（ssh）。つないだら、**読むだけ**：

| 見る物 | コマンド | ふつうなら |
|---|---|---|
| 動いているか | `pm2 status` | `aresoredorekore-backend` が **online**。restart の数が朝と同じ |
| 最近のログ | `pm2 logs aresoredorekore-backend --lines 50 --nostream` | エラーの行が続いていない |
| メモリー | `pm2 status` の mem | **90〜100 MB くらい**（16人で60分回した時 74→93 MB で平ら・11/9）。300 MB をこえて増え続けるならおかしい |
| VPS 全体 | `free -m` | available が 200 MB 以上ある |

### 止まっていた時だけ
- `pm2 status` が **stopped / errored** → `pm2 restart aresoredorekore-backend`（**部屋は消える** → 1 の手順で作り直す）
- **online なのに重い**：まず待つ（ゲームとゲームの間まで）。それでも重ければ、ゲームとゲームの間に `pm2 restart aresoredorekore-backend` → 作り直し
- **ssh もつながらない**：ConoHa のコントロールパネルで VPS の状態を見る。**料金の残高**も見る（9月はチャージ忘れでサーバーごと消えた）。止まっていれば、パネルから VPS を起動
- **ssh（IP でつなぐ）はつながり `pm2 status` も online なのに、スマホの回線でも `/fes` が開けない**：ネットの名前（DuckDNS）の問題かもしれない。当日は直せない。先生に伝えて、待つ（11/7 にも学校の Wi-Fi で名前が引けない時があった）

### やってはいけないこと
- `git push`・`git pull`・`npm install`（入れかわって部屋が消える／壊れる）
- 遊んでいる最中の `pm2 restart`・`pm2 stop`・`pm2 delete`
- `.env` を書きかえる・`nginx` の設定をさわる・`data/` を消す
- 本番にボットや検査の道具を向ける
