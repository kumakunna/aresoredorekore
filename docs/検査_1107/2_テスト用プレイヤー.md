# 2：テスト用プレイヤー（`tools/fes-bots.js`・11/7 の検査の準備）

Node と socket.io-client だけで動く「遊ぶ人」。ブラウザーは立てない（学校の PC を TV・scrcpy・測定に使えるように、軽い）。
1人＝1本の通信で、**入る → 投票 → 準備OK → 遊ぶ → 結果で「つづける」** をくり返し、ゲームを最後まで回す。

## 使い方（手元）

```bash
node tools/fes-bots.js --serve --n 8 --laps 3
```
```bash
node tools/fes-bots.js --serve --n 16 --min 30 --games bomb-coop,onaji-many,pittari,soroe,qhaya,qnear
```
```bash
node tools/fes-bots.js --url http://localhost:3001 --n 5
```

- `--serve`：検証用サーバー（`tools/dev-server.js`）を `--port`（既定 3411）で自分で立て、係（/dev-login）が部屋を作る。終わったら止める
- `--url`：立っているサーバーの、いまの文化祭の部屋に入るだけ（手元のサーバーでは `--create` で係が部屋も作る）
- `--n` 人数・`--laps` 何回遊ぶか（結果まで行った回）・`--min` 何分・`--games` 入にするゲーム（係の入／切。終わったら元にもどす）
- `--vote a,b,c`：投票するゲーム（候補は毎回3つだけなので、まだ遊んでいない物が候補にあればそれへ）・`--all`：`--vote` の全部を1回ずつ遊んだら終わる
- `--away 2`：1分たったら2人が黙る（心拍に答えない・何も押さない）→ 25秒で「はなれた」・2分で外れる、を人数の多い時に見る
- `--name テスト`：名前の頭（テスト01・テスト02…）・`--quiet`：様子を1分ごとの1行だけ
- 記録：`docs/検査_1107/fes-bots/<日時>/記録.json`（git に入れない）。回ごとのゲーム・秒・人数、**押してから返事（emit→ack）の p50・p95・最大**（操作ごと）、
  断られた返事の数、つなぎ直し・外された数、`--serve` の時はサーバーのメモリー（RSS・1分ごと）

## 遊び方（ゲームごと）

| ゲーム | すること |
|---|---|
| クイズ解除（bomb-coop）・ロシアンカード | `tools/bot-play/bomb.js`・`rcard.js`（room-bots.js と同じ台本。クイズ解除は外さない） |
| 進化じゃんけん | 手を出す段階でグー／チョキ／パー |
| みんなと同じ・みんなで早答え | 選ぶ段階で、1.5〜6秒考えてから1つ |
| ぴったり10秒 | 10秒の前後 ±1.5秒で止める |
| そろえて発射 | 時計を合わせ（clock:sync を8回・往復がいちばん短い回）、0 の時刻の前後 ±0.4秒で押す |
| 数字ちかい方 | 0〜9999 の数を打つ |

## 本番に向ける時（**はっきり指定した時だけ**。11/7 は使わない＝くまくんの決め）

- `localhost`・`127.0.0.1` 以外の `--url` は、**`--prod` を付けない限り何もつながずに終わる**
- 本番では部屋を作らない・入／切もしない（`--serve`・`--create` は本番では断る）。いまの部屋に入るだけ。名前は TV に出る（`テスト01`…）
- 使う前に決めること（3 の本番の手順で書く）：人数（16人＋余裕）・何分か・**止める条件**（あそびまちの返事が遅くなった・CPU が70%をこえ続けた・エラーが出た → Ctrl+C。
  Ctrl+C でも全員が「部屋を出る」を送ってから終わる）・だれも遊んでいない時か

```bash
node tools/fes-bots.js --url https://aresoredorekore.duckdns.org --prod --n 16 --min 3
```
