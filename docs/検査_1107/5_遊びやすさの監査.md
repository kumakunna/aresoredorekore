# 5：遊びやすさの監査（だれでも楽しめるか・11/7 の検査の準備）

数える所は道具で出した（下の「もと」）。数で決まらない所（字を読まずに分かるか・TV を見ているだけで楽しいか）は、写真とコードを見て書いた **CC の見立て** で、明日の実機で人が決め直す。
**ルール・時間・人数は変えない。見つけるだけ。**

もと：
- 画面の測り（はみ出し・字が切れる・重なり・小さい字・ボタン・コントラスト・点滅の候補）＝ `tools/fes-screen-walk.js` → `写真/walk/一覧.md`（4 と同じ）
- 色の見え方（第2色覚・第1色覚・色なし）＝ `tools/fes-screen-walk.js --vision deuteranopia` など → `写真/walk-vision-*/`
- 漢字＝ `tools/kanji-check.js` → `5_漢字の一覧.md`
- 音＝ `8_音の監査.md`

## 失敗を責める言い方・最下位を目立たせる所

- 3択を外した時の字は「つぎはきっと」（`UiText` の `ざんねん` の中身）。**「ざんねん」「失敗」「負け」「ビリ」「最下位」は、画面に出る字には無い**（`public/js/ui-text.js`・`v2-*.js` を探した。ui-text.js の決まり「失敗しましたと書かない」）
- 最下位を目立たせる所：結果の順位は TV に出る（大切なこと5 の※：対戦の結果は出してよい）。いちばん下の人だけに印が付く所が無いかは、写真で見る（このあとに足す）
