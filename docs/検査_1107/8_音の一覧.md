# 8：鳴る音の一覧（`node tools/sound-sites.js` が作る）

- だれが鳴らすか（`public/js/sound.js`）：**TV で鳴らす。スマホは tap（押した時のコツ）だけ。** TV が無い遊び方の時だけ、スマホでも鳴らす。司会の声は止めてある（`VOICE_ON=false`・読み込みもしない）
- 同じ音は同時に3つまで（`MAX_SAME`）。音量のつまみ（効果音）が 0 なら鳴らさない。iPhone はウェブから振動しない（振動の列は Android だけ）
- 測った数：`tools/sound/measure-sound.py`（`docs/検査_1107/8_音の測り.json`）。M最大＝瞬間の大きさの最大（LUFS）・TP＝トゥルーピーク（dBTP）・4k↑＝4kHz より上の強さ（全体に対する dB）。
  印（仮の線）：TP −1 dBTP 超／4kHz より上が −10dB より強い／5ms より急に鳴り、しかも M最大 が −26 より大きい
