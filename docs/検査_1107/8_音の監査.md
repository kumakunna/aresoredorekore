## 明日の手順：会場のうるささの中で聞こえるか（人の耳で）

TV の PC で、だれも遊んでいない時に（部屋の進行は止めなくてよい・TV の画面で鳴らすだけ）。

1. TV の PC の Chrome で `/fes?tv=1` を開き、画面を1回クリックする（音の箱を起こす）
2. F12 →「Console」に、下の1行をはりつけて Enter（音を1つずつ、名前を出しながら2.5秒おきに鳴らす。**アプリは何も変わらない**・読み込み直せば元どおり）
   ```js
   (async()=>{await Sound.preload();const ids=['tick','count','decide','ok','ng','miss','timeup','cut','spark','cheer','fanfare','defuse','boom'];for(const id of ids){console.log('▶',id,Sound.play(id,{force:true}));await new Promise(r=>setTimeout(r,2500));}})()
   ```
3. TV の音量を決める：まず **爆発（boom）と解除（defuse）が、TV の前 1m で「大きいけど痛くない」** 音量にする。そのまま 3m 下がって、tick（時計）と count（3-2-1）が聞こえるかを見る
4. 電子レンジ・たこ焼き・人の声がある時に、もう一度 2 を流して、聞こえない音に印を付ける（チェック表「音」の行のメモに）
5. **耳に刺さるか**：tick・defuse・fanfare（2本目）・cheer（1本目）を、子どもの耳の高さ（TV の前 1m・しゃがむ）で聞く。刺さるなら、その音の名前と本数をメモ（直すのは夜・作り直しは `tools/sound/make-se.py`）
6. BGM：係の画面で BGM を「入」→ 待合で鳴る・投票で止まる・ほかの音とぶつからないか
7. 決めた TV の音量（目盛りの数）をメモする（当日の朝の手順に足す）
