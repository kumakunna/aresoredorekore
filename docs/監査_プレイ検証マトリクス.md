# 監査：プレイ検証マトリクス（第35弾フェーズB）

全ゲーム×全ルートの検証台帳。**行の一覧は`tests/inventory.js`の`CASSETTE_GAME_IDS`（`public/index.html`のCASSETTESから自動抽出）が正**で、
全ゲームぶんの行があることを`tests/room-paths.js`が機械照合する（行頭セルにゲームidを書く約束。ゲームを足したら行を足さないとテストが赤くなる）。

## セルの書き方

- `未` … まだ検証していない
- `OK` … 実サーバーで実際に操作して問題なし（確認日を添える）
- `バグ→修正済` / `バグ→気づき` … 見つけた問題と行き先（詳細は下の発見メモ）
- `—` … 該当なし（その遊び方が存在しない）

## 列の意味

1. **手渡し**：1台をまわす方式での通しプレイ（セットアップ→全フェーズ→結果）
2. **部屋**：1人1台方式での通しプレイ（大画面なし。部屋を立てる→参加→開始→決着）
3. **大画面**：大画面表示モードを1台加えた状態での通しプレイ
4. **再戦**：結果画面→「もう一度」→状態の持ち越しなく始まるか
5. **中断**：ゲーム途中での中断手段すべて（設定→終了／部屋を抜ける／ゲームをえらびなおす）
6. **最少**：最少人数での通しプレイ（開始ボタンの下限も両方向確認）
7. **最大**：最大人数（上限なしのゲームは大人数＝目安30人）での通しプレイ

## 対象外（理由つき）

- **hiddenモード**（秒でこれ・クイズ王決定戦[手渡し旧]・早押し[手渡し旧]・オークションバトル[手渡し旧]）：`hidden:true`で棚から選べず、プレイヤーが到達できない。退行は`tests/`（`showHiddenModes`）が見張っている。復活させる時にこの表へ行を足す
- **部屋の開始合図（3-2-1）・退室・部屋ボタン**：フェーズAで全ゲーム検証済み（`tests/room-paths.js`・`tests/rt-screens.js`で恒久化）。この表では「通しプレイ」の中身を見る
