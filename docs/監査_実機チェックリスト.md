# 監査：実機チェックリスト（第35弾D・くまくんへの依頼）

検証環境（ブラウザ自動運転）では再現できない、**実際のスマホでしか確かめられない項目**だけを残したリスト。
それ以外の異常系はすべて自動検証済み（`tests/abnormal.js`・`docs/監査_異常系シナリオ.md`参照）。

## 1. スリープ→復帰（d05）——スマホ2台以上で

準備：スマホ2台＋PC等でもう1人（計3人）で部屋を作り、ワードウルフを開始して**投票の画面**まで進む。

- [ ] A. スマホ1台を**画面ロック（スリープ）**して2〜3分放置 → 残りの端末に「◯◯さんが席を外しました」系の表示が出るか
- [ ] B. スリープ中に残りの2人で投票を済ませる → **スリープ中の人を待たずに**結果へ進むか（自動検証済みの挙動が実機でも同じか）
- [ ] C. スリープから復帰 → 画面が**いまの状態**（結果 or 次の段階）に自動で追いつくか。
      追いつかない場合、リロード→部屋コード＋同じ名前で入り直して復帰できるか
- [ ] D. 復帰した画面の**自分のお題・役職が正しい**か（前の段階の古い表示や、他人の情報が出ないか）
- [ ] E. スリープ直前に押しかけたボタン（押した瞬間にロックした等）が、復帰時に**二重に効いていない**か
      （票が2票になっていない・「もう投票済みです」等で正しく断られる）

補足：Bの間にホスト端末をスリープさせるパターンも1回試せると理想（→残りの端末に「進行役が◯◯さんに移りました」
相当の変化が起き、進行が止まらないこと。d03の自動移譲の実機確認）。

## 2. 大画面のピクセルの見栄え（フェーズCの持ち越し）

検証環境ではテキスト・構造の確認まで（描画フレームが取得できない）。TVやモニタに映した時の**見た目**だけ確認：

- [ ] 部屋の大画面表示をTV/モニタに映し、以下を1〜2ゲームで流し見る：
      文字が遠くから読めるか／レイアウト崩れ・はみ出しがないか／
      爆弾解除の横棒グラフ・クイズの伏せ字・決着表示が綺麗に出るか

## 3. 通信の弱い場所での体感（余裕があれば）

- [ ] Wi-Fiの弱い場所（会場の隅など）で1ゲーム遊び、操作の引っかかり・復帰の自然さを体感で確認

## 4. 第36弾（36-1・36-2・36-5・36-6）——実機の目と指でしか分からないところ

数値・DOM・計算色までは自動で確かめてある。残るのは「見え方」と「触り心地」だけ。

- [ ] 4-A **トグルの見分け（36-5）**：設定と、人狼・爆弾解除・クイズ王・オークション・すごろくの
      各テーマ配下でトグルを1つずつ見て、ON/OFFが**ひと目で**違って見えるか。
      計算上の色は OFF=#A9A49A 固定／ON=テーマ色（共通#C08A3C・人狼#7C8AE0・爆弾#3FBFA5・
      クイズ#F0B429・オークション#D4A537・すごろく#C0392B）。
      暗いテーマで沈んでいないか、明るい場所で薄すぎないかは実機の画面でしか分からない
- [ ] 4-B **四隅（36-6）**：季節の風鈴は出さないことにした。
      設定の⚙・戻る矢印・リアクション・ありがとうが、指で押し間違えない距離にあるか
- [ ] 4-C **時間の見せ方（36-2）**：「見たい時だけ」で、遊びながら時計を押して覗く動きが
      邪魔にならないか（5秒で閉じる長さが短すぎ／長すぎないか）
- [ ] 4-D **3-2-1（36-1）**：飛ばせなくしたので、2周目・3周目に「待たされる」と感じないか。
      感じるようなら、秒数を減らす相談をしたい（飛ばせるようには戻さない）

## 5. 第37弾（ルールを読んで「準備OK」）——実機の目と指でしか分からないところ

通信・状態・画面の中身は自動で確かめてある。残るのは「読む気になるか」「待たされ方」だけ。

- [ ] 5-A **読む長さ**：ルール画面を実際にスマホで読んでみて、
      箇条書きが多すぎて読み飛ばしたくならないか。とくに人狼（7項目）と、
      すごろく系（説明が長いもの）
- [ ] 5-B **待たされ方**：3人以上で、わざと1人だけ押さずにいる。
      残りの人の画面に「〇〇さんを待っています」が出て、
      **責められている感じにならない**か（言い回しを変えるならここで言ってください）
- [ ] 5-C **2周目**：同じゲームを「もう一度」した時、ルール画面が出ずに
      待合の「準備OK」だけになるのが、**分かりやすいか／不親切か**
- [ ] 5-D **自動で始まる瞬間**：最後の1人が押した瞬間に3-2-1が始まる。
      押した本人が驚かないか（押す→即はじまる、が急すぎないか）
- [ ] 5-E **進行役の下見**：モードのカードの「📖 ルールを見る」が、
      押し間違いを誘わないか（カードそのものを押すつもりで、こちらに当たらないか）

## 6. 第38弾（相場オークション）——実機の目と指でしか分からないところ

画面が本当に描かれるか・秘密が漏れないか・数が合うかは自動で確かめてある。
残るのは「competing の手ざわり」だけ。**3人以上**でお願いします。

- [ ] 6-A **開場の一覧性**：6品がならんだ画面を見て、
      **見比べて悩む気になるか**。1品ずつしか見えなかった前の版と比べて、
      「次を待つ」という選択肢が実感できるか
- [ ] 6-B **系統の名前**：🏺壺もの／🖼絵もの／💎光もの が、
      日本語として自然に読めるか（相場の帯に3つならんだ時に、
      同じ種類の言葉として一目で読めるか）
- [ ] 6-C **競りの速さ**：せり上げ式で、値がついてから14秒。
      **速すぎて置いていかれないか／遅すぎてだれないか**。
      とくに「ヒントが開いた直後に木槌が落ちる」感じにならないか
- [ ] 6-D **入札ボタン**：片手で押せるか。「+1 / +3 / 額を指定」の3つで足りるか、
      それとも刻みが足りないと感じるか
- [ ] 6-E **値踏みの間**：落札できなかった人が3択を出す6秒。
      **考える間があるか、それとも急かされるか**
- [ ] 6-F **開示の順**：予想 → 品質 → 相場 → 得点 の順に出る。
      この順で「おお」となるか、それとも待たされる感じか
- [ ] 6-G **リアクションの絵文字バー**：画面下のボタンに重なって読みにくくないか
      （全ゲーム共通の既知の問題。直したあとの確認用）
- [ ] 6-H **2ラウンド目の棚**：1ラウンド目に鑑定眼で見た品があっても、
      2ラウンド目の開場では**どの品も「?」に戻っている**か。
      品番号は毎ラウンド1〜6に戻るので、残っていると別の品の品質が出る。
      （サーバー側は tests/realtime-auction.js で固定済み。
        画面で見えることだけ、まだ目で確かめられていない）
- [ ] 6-I **1ラウンドの長さ**：秘密入札で、実際に何分かかったか。
      設定画面の「およそ○分」と、体感がどれくらいずれるか。
      とくに**誰も入札しない品が続いた時**（流れた品は1回だけ出直すので、
      1ラウンドが最大12品ぶんに伸びる）に、長すぎないか
