# ゲーム会社の社員として画面を見た時に思うこと（2026-11-05）

くまくんの頼み：「あなたはゲーム制作会社の社員として、画面を見たときどう思うのかもまとめてください」。
ここは**感想**。事実と証拠は [レポート_客観検査.md](レポート_客観検査.md) と [指摘の全部.md](指摘の全部.md) にある。
立場は「パーティゲームのチームで、UI とゲームの手触りと運営を見ている社員」。お世辞は書かない。

---

## 1. 最初の30秒の印象

**「学生の個人制作だと言われたら、作り方（プロセス）の方に驚く。画面だけ見たら、新しい所と古い所の差に驚く。」**

- 入口・名前・光と揺れの確認・投票・決定・結果（文化祭の流れ）は、**ちゃんと「商品の顔」をしている**。
  黒い太字と黄色の地、右へ伸びる矢印、小さな英字の見出し（Vote! / Next Game / Boom...）。どの画面も「いま何をする画面か」が1行目で分かる。
- ところが ⚙ を1回押すと、クリーム色に明朝体の別のアプリが出てくる。ルールと準備OK は暗い紫、1台モードは桃色。
  社内レビューなら最初に言われるのはこれ：**「同じ製品に見えない」**。お客さんは中身でなく、見た目の割れ目で「作りかけ」と判断する。
- 遊ぶ画面（クイズ解除の5×6の盤）は、数字のマスが大きくて押しやすい。3-2-1 から盤まで迷わない。ここは良い。

## 2. 社内で「これは真似したい」と言う所

1. **思想が先にあって、それが決まりに落ちている。**「スマホを人を集める道具に」「責める時は静かに」「序列を見せない線は勝ち負けに関係あるか」——
   こういう線引きを文章にして、テストの見張り（`tests/realtime.js` の「部屋が配るメンバーの項目は8つだけ」など）まで落としているチームは、会社でも多くない。
2. **人のいない運営（文化祭の部屋）。**投票→決定→準備OK→遊ぶ→結果→待合が、係が何も押さなくても回る。アーケードの「デモ画面→コイン投入」の考え方をパーティゲームでやっていて、展示の作りとして正しい。
3. **TV とスマホの役わけ。**TV は舞台（大きな札・名前の壁・QR・のこり秒）、スマホは手元（押すだけ）。QR がほぼずっと出ている（あとから来た人がすぐ入れる）。
4. **安全の確認が「同意」ではなく「設定」。**光の点滅・揺れ・文字の大きさを最初に1画面で切れる。押しつけがましくなく、必要な人には効く。名前の記録も「不適切な言葉の対策のため、1か月記録します」と正直に書いてある。
5. **検査の厚さ。**110 のスイート、わざと壊して検査が赤くなるかを見る変異、耐久3時間、いじわるテスト50台。個人でここまでやる人はまずいない。
6. **数字で振り返る道具がある。**`/fes/bomb-stats`・`/fes/rounds`・感想の★。遊ばせて終わりにせず、記録を見て直す前提で作ってある。

## 3. レビュー会で必ず指摘される所（重い順）

### 3-1 いちばん見せたい場面が、まだ一度も起きていない
クイズ解除（協力）は文化祭の看板のはずなのに、本番5試合はすべて爆発、しかも**180秒のうち14〜28秒で終わっている**。
ゲームデザインの言葉で言うと、**「中心の体験（みんなで解除した！）に誰も届いていない」**。解除の幕・全員の名前・紙ふぶきを作り込んでも、見た人がいない。
会社なら、演出を足す前に「協力ゲームの勝率はまず50〜60%を目標にして、遊ばせて、数字を見て合わせる」をやる。
ライフ7に上げた版はまだ本物の試合が0回。**11/6 のリハーサルは、勝率を決める場として使うのがいちばん価値が高い**。

### 3-2 人の名前を大きな画面に出すのに、最後の網に穴がある
TV に知らない人の名前（打った字）が大きく出るのは、パーティゲームでいちばん事故が起きる所。
会社なら「係が隠したら、どの画面からも消える」は**出荷を止める条件**になる（今はゲーム中と結果に元の名前が出る・G2）。
帰った人の名前が待合に残り続けるのも（G1）、ネットのゲームでよくある「幽霊プレイヤー」で、見た人に「壊れてる？」と思わせる。

### 3-3 運営画面の「取り返しのつかないボタン」
係の画面は10個のボタンが同じ形・同じ重さで並ぶ。「一時停止」の隣に「この回をとばす」（確かめ無しで16人のゲームを消す）、
「感想（3件）」と同じ見た目で「部屋を作り直す」。運営のツールの基本は**「危ない物は色と場所と確かめで分ける」**。
本番の現場では、係は立ったまま・片手で・お客さんと話しながら押す。

### 3-4 見た目が4つに割れている
新しい黄色（v2）・暗い紫のルール・桃色の1台・クリームの設定。文化祭の流れは黄色だけで通れるので当日は目立たないが、
ふだんの部屋では**全員が必ず古いルール画面を通る**（大切なこと6の、いちばん大事な画面）。製品としての優先は「全員が通る画面」から。

### 3-5 入口の壁
入口の3つのボタンのうち2つ（部屋をつくる・1台で遊ぶ）がログインで止まり、登録には合言葉が要る。
文化祭の外で初めて触った人の多くは、ここで帰る。会社なら「入口→最初の1ゲーム」までの離脱を測って、真っ先に下げる所。
（文化祭は /fes から入るので当日は関係が薄い。文化祭の**あと**に効いてくる）

### 3-6 TV の画面の使い方
投票の TV（1920×1080）は、札が上の左寄りにまとまっていて、下半分が飾りの斜めの字だけになっている。
教室のうしろから見る物は、**「いちばん大事な1つを、画面の半分の大きさで」**が基本。3枚の札と残り秒をもっと大きくできる。
（長い名前16人の TV で名前が「…」で切れるのも、同じ「TV の字が小さい」の仲間）

### 3-7 モードの漏れ
文化祭のスマホの ⚙ から、ふつうの部屋の「この画面を大画面にする」「部屋を出る」が押せる（Z1・Z2）。
押すと文化祭の出口（感想・もう一度入る）を通らずにふつうの入口へ出る、または自分が TV になる。
大切なこと9（借りたものは世界観ごと運ばれる）の典型で、会社なら「モードごとにメニューの中身を決める表」を作って防ぐ。

## 4. 画面ごとの一言

| 画面 | 一言 |
|---|---|
| 入口 | ロゴと3つのボタンは潔い。ただ「1台で遊ぶ」以外の2つが壁（3-5）。ログイン中の表示「kumakunn さんでログインしています」はお客さんには要らない情報 |
| 名前を入れてね | 良い。「ニックネームでOK。本名は出さないでね」「8字まで 2/8」は親切。むずかしさの札は絵つきで分かりやすい |
| 光と揺れの確認 | 良い。3つのスイッチで十分。「あとから右上の ⚙ でも変えられます」も正しい |
| 投票（スマホ） | 札3枚が上に固まり、下が大きく空く。札を大きくするか、空いた所に「いま◯人が投票」などの手応えを |
| 決定（TV） | 爆弾の絵と「クイズ解除（協力版）」が大きくて良い。ここは「アドレナリンが出る」側にもっと振れる（音と光の山） |
| 遊ぶ（スマホ） | 数字のマスは押しやすい。むずかしさを色の縁だけで伝えている（凡例は3色・入る時は2つ）のは直したい |
| 爆発の結果 | 「0本」を大きく出す・「あと30本だった！」は、0本の時は静かな言葉に（責める時は静かに）。称号の知らせがボタンにかぶる（A1） |
| 待合（文化祭） | 名前の札・いま部屋にいる人・次の候補・感想の★、と情報がきれいに並ぶ。★を押させる位置も自然 |
| 係の画面 | 情報（いま・部屋・TV・今日の回数）は良い。ボタンの重さの差が無い（3-3）。「名前の記録を読む（くまくんだけ）」はくまくんにしか出ないのに字が長く、そのボタンだけ2行に折れる。右上の ⚙ は古い設定へ行く（係の設定ではない） |
| ⚙ の設定 | 別のアプリに見える（3-4）。どのページの下にも「ログアウト」と絵文字の著作権表示が出る |
| 名前を変える | ← が見出しに重なっている（F1）。社内なら「見た目のバグ」として即直す |
| TV のリモコン（/tvs） | 道具としては分かりやすい。「× 切れている」が何を指してどうすれば直るのか書いてない（B5） |
| あそびまちのモニター | 呼び出しの電光掲示板の見た目は楽しい。「あそべるゲーム」が空だと右上がぽっかり空く（空の時の一言が欲しい） |

## 5. 自分がこのプロジェクトのディレクターなら（文化祭まであと1週間）

**やる**
1. 11/6 のリハーサルで、クイズ解除の勝率を決める（ライフを2通り用意して比べる）。演出はさわらない
2. 名前の網を閉じる（隠す→全部の画面・帰った人を外す）
3. 係の画面の危ないボタンに確かめを付け、「困った時」の紙を1枚作る
4. 朝の表と、自動反映を止める手順を紙にする。あそびまちの札の URL を /fes に
5. 見た目のバグ（名前を変えるの重なり・称号の知らせのかぶり・TV の斜めの線）だけ直す

**やらない**
- 新しいゲーム・新しい演出・古い画面の入れかえ（文化祭のあと）
- 11/12 より後の push（決めたとおり）

## 6. 観点ごとの点（5点満点・社員の主観）

| 観点 | 点 | ひとこと |
|---|---|---|
| 考え方（コンセプト・原則） | 5 | ここがいちばん強い。説明できる「なぜ」がある |
| 文化祭の流れ（新しい画面） | 4 | 迷わない。TV の使い方と、0点・爆発の時の言葉で1点引く |
| ゲームの手応え（バランス） | 2 | 看板のクイズ解除がまだ勝てない。数字で合わせる段階 |
| 見た目のそろい | 2 | 新しい所は4点、全体だと割れている |
| 運営のしやすさ（係） | 3 | 道具はそろっている。危ないボタンと「困った時」が弱い |
| 安全・個人情報 | 3 | 考え方は良い。名前の網に穴（G2）がある |
| 作り方（検査・記録・ドキュメント） | 5 | 会社の平均より上 |

**総じて**：「土台と作り方は会社のチームより丁寧。足りないのは、**遊ばせて数字で合わせる**最後の1周と、**全員が通る画面の見た目をそろえる**こと」。
文化祭は、そのための一番いい実験の場になる。
