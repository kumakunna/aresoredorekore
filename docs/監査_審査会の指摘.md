- **時間は機械の操作の時間**。人が読む・考える時間は入っていない。bot は人より速く答えるので、**「他の人待ち」は実際より短い**

- あれそれの「他の人待ち」は、説明役がお題を説明して誰かが当てる時間（1ラウンド3分）
- 検証の都合で出たものは数えていない：QRの下の「この端末だけのURLなので…」（localhost のため）、検証用ユーザー kensho34 にたまった記録
