### 棚卸しで見つかった「効かない設定」の始末（2-4）

| 見つけたもの | どう直したか |
|---|---|
| `titleFanfare` に設定の窓口が無く、**一度切ると二度と戻せなかった**（案内文も存在しない行を指していた） | display に行を足した（F5-7が両方向を見る） |
| `fxFlash` の JS 側の門を**読む行が1つも無かった**（効いていたのはCSSの1行だけ） | `fx.js` の `flash()` が門を読むようにした（F5-8） |

| `seVolume` が爆弾の心拍に届かない（出口が使い回される） | `refreshSfxGain()` で作り置きの出口も直しに行く（F5-1） |
| `fontScale` の中央4段が1pxも動かない | 段ごとにトークンを書いた（F5-5） |
| `fxBody` が、開いたままの同意画面に効かない | 切り替えたら描き直す（rt-screens） |
| 「このゲームの設定」に、何も起きない項目が11モードに出る | `liveGameSettings()` をデータ駆動にした |
