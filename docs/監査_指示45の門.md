### 45-1：残り時間が見えない

**前提の1つが事実と違った。**

| 確かめたこと | 結果 |
|---|---|
| コードの既定値 | `timerView: 'always'`。git で追うと**第36弾の導入時から一度も `peek` だったことはない** |
| 本番の配信物 | `https://aresoredorekore.duckdns.org/` を取得し、改行コードを揃えて `diff` → **1バイトも違わない**（落とし穴15はクリア） |
| まっさらな端末 | `localStorage` 空で起動 → `data-timer-view="always"` |
| 実際に協力版・部屋を開始 | 時計は `00:58` と出る。隠れない |

**「残り数秒で突然赤い `00:06` が出た」の原因は割れた。**
`peek` にして走らせると、残り10秒（`.warn`）で仮面が破れる：

```
残り50秒 : color rgba(0,0,0,0) / ::after "--:--"   ← 仮面が効いている
残り10秒 : color rgb(255,143,128) / ::after "--:--" ← 数字が赤く透ける
```

`.app.theme-bomb .timer-chip.warn`（index.html:3007）と
`.app[data-timer-view="peek"] [data-timer]:not(.peek-on)`（index.html:401）は
**詳細度がどちらも 0,4,0** で、後ろにある爆弾テーマが勝つ。設計ではなく事故（落とし穴23）。

**再現の途中で、同じ主題の事故をもう1つ見つけた。**
再戦（「もう一度」）で制限時間が `0:01` になる。開始直後に `00:01` → 即爆発を**2回観測**。
ウィザードのホイールが `00:01` を指しており `state.customTimer = 1`
（`1 || 180` なので既定にも落ちない）。45-1 に含めて直した。
