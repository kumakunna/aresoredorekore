## L5 49-2：全画面×3サイズで主ボタン・主要情報が初期表示に入る

### 直したのは1行。**作りは最初から正しかったのに、効いていなかった。**

`.wiz-body` は `flex:1; overflow-y:auto`＝「余った高さのぶんだけ出して、あふれたら巻く」
つもりで書いてあり、`.wiz-foot` も `margin-top:auto` で下に貼り付くつもりだった。

効かなかった理由は `.screen` が **`min-height` しか持っていなかった**こと。
下限しか無いので中身が増えれば画面はいくらでも伸び、
伸びれば `flex:1` は「余った高さ」を計算できず、`overflow-y:auto` は一度も働かない。
**本文が伸びきって、その下の「つぎへ ▶」が折り返しの外へ押し出されていた。**

    .screen:has(> .wiz-body){max-height:100dvh;}
    .wiz-body{ …… min-height:0; }   ← 縦並びの flex では、これが無いと overflow が負ける

**余白は1pxも削っていない。押す的も縮めていない**（49-2の禁止）。

## 49-5：**直すべきか迷う文言**（指示 §3「まとめて聞く」の分）

**勝手に直していない。**どれも「直すと良くなるかもしれないが、
いま決まっている形を崩す」たぐいのもの。数字は `node tools/triage-ui-text.js` の実測。

### ① 動詞のかな寄せ（正本10「ひらがな寄り」の適用範囲）

正本10は「ひらがな寄り」と書いてあるが、
見張り（`BANNED`）が掃いているのは**ボタンの札だけ**。
本文では漢字とかなが両方使われている。

| 語 | かな | 漢字 | 気になる点 |
|---|---|---|---|
| あそぶ / 遊ぶ | 27 | 16 | いちばん数が多い |
| つかう / 使う | 3 | **14** | 漢字のほうが多い |
| はじめる / 始める | 7 | 4 | |
| つづける / 続ける | 1 | **5** | 漢字のほうが多い |
| とじる / 閉じる | 1 | 3 | **同じダイアログの中で割れている**——見出し「部屋を閉じますか？」／ボタン「とじる」 |

**私の考え**：全部かなに寄せると、文の中の漢字が減りすぎて逆に読みにくくなる可能性がある
（「みんなであそぶときにつかう」）。
`BANNED` が札だけを掃いているのは、**そこが押す前に読む最短の言葉**だからで、
本文まで広げるのは別の判断だと思う。
ただし**「閉じる／とじる」が1つのダイアログの中で割れている**のは、
どちらに寄せるかだけ決めてもらえれば直せる。

### ② 「ゲスト」（1件・`自分がゲストになる`）

`JARGON` に **ホスト→進行役** はあるが、**ゲストは無い**。
`ui-text.js` のコメントには
「『ホスト／ゲスト』は、初めて来た人にはどちらが自分か分からない」と書いてある——
**片方だけ直っている状態。**

**私の考え**：「進行役をやめる」のほうが分かりやすいが、
これは画面の名前（`ROLE.ゲストになる`）なので、
言い換えると「自分が進行役をやめる」になり、少し長い。判断をもらいたい。

### ③ 遊ぶ人にできないことを頼んでいる1件

`写真が大きすぎます（端末側で縮小してから送ってください）`（realtime.js）

**遊ぶ人に「端末側で縮小」はできない**（アプリが勝手に縮めている）。
括弧の中を落として「写真が大きすぎます」だけにするか、
「もう少し小さい写真でどうぞ」にするか。

### ④ 口調が浮いている1件

`アルバムは個人情報保護の観点から、サーバーから消されます！`

**ここだけ役所の言葉づかい。**しかも「！」が付いている。
ほかの安全の説明（「写真はわたし終えたらサーバーから消します」）は
ずっと素直な言い方なので、そちらに寄せたい。

### ⑤ 「はずれ」「ちがいます」「不正解」がゲームごとに違う

| 言い方 | 出る場所 |
|---|---|
| ❌ はずれ | クイズ（ラッシュ） |
| ❌ ちがいます | つぎつぎクイズ |
| ❌ 不正解 | あれそれ・オークション |

**私の考え**：そろえたほうがよいが、
ゲームごとの空気（早押しの「はずれ」と、オークションの「不正解」）を
わざと変えている可能性もあるので、意図を聞いてから。

### ⑥ 残す外来語の候補（`KEPT` に無い）

| 語 | 件数 | どこ |
|---|---|---|
| ブラウザ | 1 | このブラウザは音声認識に対応していません |
| メンバー | 3 | メンバーを入力しなおしますか？ ほか |
| 端末 | 多数 | 端末を振る・この端末では… |
| socket.io | 1 | socket.io が読み込めていません（rt-client.js） |
| クエリ | 1 | name クエリが必要です（server.js・開発者向け） |

**私の考え**：「端末」は言い換えにくい（「スマホ」だとTV・PCが外れる）ので `KEPT` に載せたい。

## 測定そのものについて（落とし穴28）

この指示では、**測る道具が2回嘘をついた。**どちらも記録済みの型。

1. **`getComputedStyle().backgroundColor` が遷移の途中で止まっていた**（落とし穴47）。
   枠が裏に回っていると `document.timeline.currentTime` が 0 のままなので、
   人狼のテーマを当てたのに**共通のクリーム**が返り、爆弾では**途中の灰色**が返った。
   → 遷移を切ってから測り、**宣言値と computed が一致すること**を毎回確かめる形にした
2. **`window.scrollY` が当てにならなかった**（落とし穴45の親戚）。
   `innerHeight`(870) と `clientHeight`(812) が食い違い、
   枠のほうが背が高いぶん、はみ出していてもスクロールが起きない。
   375×667 でも `scrollHeight − clientHeight = 196` に対し実際に届くのは 148 だった。
   → **折り返しの権威は `clientHeight`**、はみ出しは**要素の矩形**で見る。
   実スクロールは参考値として並べるだけにした
