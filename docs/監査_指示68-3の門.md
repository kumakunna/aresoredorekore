## 決めたこと（指示書に無かった所）

- **段階の名前は `unveil`**：`open` は False or True の「ケースが開く」に取られていて、段階の札の表は全ゲームで1枚（落とし穴2）
- **ふだんの部屋の TV も新しい見た目**（`scr-v2-onaji-tv`）。今までの大画面（`scr-rt-big`）は通さない
- **スマホも開いた結果（棒と冠）を出す**：TV が無い部屋ではスマホしか見る物が無い。点になった時だけ「+1点！」と音（責める時は静か）
- **世界（色と印）を1つ足した**（藤色・`v2-w-onaji`／`theme-onaji`）。ほかのゲームの世界を借りない（大切なこと9）。世界の数を手で書いていた検査は 10→11
- **称号**：指示書の2つ（いちばんみんなと同じ・ひとりだけ）を結果に出し、数える箱と顔4つ（みんなの証・以心伝心・わが道・一致団結）。照らすのは名前でなく id
- **クリア演出**：多い方・少ない方は点がいちばんの人、一致団結は5問とも全員そろった時だけ全員を祝う
- **リアクションの帯は出さない**（新しい見た目の画面・TV には押す人がいない）
- 文化祭の検査（`tests/fes.js`）の「全部 on」は**テスト中をのぞく**：候補が4つになると直前のゲームが外れ、門2の前提が崩れた
