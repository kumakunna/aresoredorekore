## 分かったこと

- **見えていないタブの `setInterval`（2秒）は、5分をすぎると約1分に1回になる**（Chrome の強いタイマーの遅らせ）。にせのモニターの測り：setInterval の間は最大 60.0秒。
  いっぽう「聞きに行って、返事が来てから setTimeout」の形は、裏で6.5分たっても約3秒のまま（最大 3.03秒）。
  **本物のあそびまちのモニターがどちらの形かで、裏のチャイムが最大1分おくれるかが決まる**（聞きたいこと）

- **裏の動画は止まる。**Chrome は、音を消した見えないタブの動画を止める。表にもどすと、止まった所から続く（頭にはもどらない）。
  「一度も表に出していない動画」は、はじめて出した時に頭から始まる
- **はじめての日だけ、あつまれのタブに「光と揺れの確認」が出る**（端末ごとに1回・アプリの決まり）。TV の PC で、TV① と TV② のあつまれに1回ずつ［はじめる］を押す（運用メモに書いた）
- 文化祭の部屋ができると、TV のタブは自分で1回 `/?room=…` へ移る（表でも裏でも同じ・アプリの今のふるまい）
- Chrome for Testing には `background.js` という名前の別の拡張機能もいる。道具は「はじめる」の画面から拡張機能を見つける
