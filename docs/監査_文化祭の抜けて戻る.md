# 調べもの：文化祭の部屋（/fes）で「途中で抜けて戻る」（2026-10-29）

くまくんの調べもの（2時間まで・コードは直さない・main へ push しない）。結果を見て、直すかを決める。
検査：`tests/fes-rejoin.js`（本物のサーバー・11件・いまの動きを記録する形。「本番で困る」と書いた行は、直したら新しい決まりに書き換える）。
ゲームは文化祭の4本（クイズ解除・みんなと同じ・ぴったり10秒・そろえて発射）。クイズ王2（枝 shiji68-5）は入れていない。

## 1. memberId を持たずに同じ名前で入り直す（ちがうブラウザ）

- **起きた事**：別人「ふう②」になる。元の「ふう」は切れたまま名簿に残る。遊んでいる途中なら「ふう②」は今回は待つ（理由「おくれて来た」）。
  ふだんの部屋は「切れている同じ名前の枠を引き継ぐ」（第24弾-3）が、**文化祭だけ、名前の重なりを「②」にする確かめが先にある**ので引き継ぎに届かない（`realtime.js` room:join：`NameFilter.dedupe` が「切れた同名を探す」より前）。
- **本番で困るか**：困る。スマホを替えた・別のブラウザで開いた・記憶を消した人は、元の点に戻れない。名簿に切れた「ふう」と「ふう②」が並ぶ（16人の席も1つ使う：切れた人は数えないので満員にはならないが、名前は残る）。
  ただし同じブラウザなら memberId が残る（端末の記憶）ので、ふつうの「画面を消した」「読み込み直した」は 5 のとおり戻れる。
- **直すならどこか**：`realtime.js` room:join の文化祭の門。名前の確かめ（8字・使えない言葉）のあと、`dedupe` の前に「切れている同じ名前の枠」を探して引き継ぐ。
  決めること：同じ名前の別人が、切れた人の点を取れてしまう（名前しか手がかりが無い）。待合と準備OK の間だけ引き継ぐ、などの線を決める。

## 2. 準備OK の間に切れて戻る

- **起きた事**：
  - 締め切りの前に戻れば（同じ memberId）、今回に入れる。押していなければ押していないまま（押し直す）。押していた時は、その印が残る（入り直しで消さない・コードを読んだ所見）。
  - 押したあとで切れて、締め切りまでに戻らなかった人は今回は待つ。戻った時の理由が **「押したが上限で入れなかった（full）」** と出る（ほんとうは切れていた）。
  - 押さずに切れて締め切りのあとに戻った人は、理由「押さなかった（つぎの回から入れます）」。切れていた間は「押さなかった回数」（2回で席を空ける）に数えない。
  - **画面を消したまま（つながったまま返事が無い）の場合**：サーバーが「切れた」と見るのは 25秒（`HEARTBEAT_TIMEOUT_MS`）。準備OK は 20秒なので、その間ずっと「いる人」として数えられ、押さなかった扱い（1回）。**2回つづくと席が空く（部屋から外れる）**。また「全員そろったら のこり3秒」も、その人を待って縮まない（コードを読んだ所見・25秒待つ検査は書いていない）。
- **本番で困るか**：理由の「いっぱい」はうそになる（小さい）。画面を消したまま2回で外れるのは、文化祭では「スマホを置いて見ている人」が外れる形で、困るかもしれない（席を空けるための決まりなので、狙いどおりとも言える）。
- **直すならどこか**：`fes-room.js` closeReady の `fesBench`（切れていた人は 'missed' か別の理由に）。25秒と20秒の関係は `HEARTBEAT_TIMEOUT_MS` か `TIMES.readyMs`。

## 3. 抜けている間の点と、結果の画面

- **起きた事**（ぴったり10秒で確かめた）：切れた人は名簿に残るので、結果の順位に入る。点は切れる前の回の分だけ（抜けている間の回は0点・押せない）。memberId なしで入り直した「ふう②」は結果に入らない。
- **本番で困るか**：小さい。順位の下の方に「切れた人」が並ぶだけ。ただし 1 と重なると「ふう」と「ふう②」の2人ぶん名前が出る場面がある（結果に出るのは元の「ふう」だけ）。
- **直すならどこか**：直さなくてよいと思う。1 を直せば重なりは消える。

## 4. 同じ memberId で2本つなぐ（タブ2つ）

- **起きた事**：名簿は1人のまま。どちらのタブからも押せるが、二重には入らない（準備OK は同じ印・ゲームの押す操作は2回目が `already_stopped`）。
  **本人だけの秘密（wolf:you）は、あとからつないだタブにだけ届く**。前のタブは押せるのに自分の様子が変わらない。前のタブを閉じても「切れた」にはならない。
- **本番で困るか**：小さい。文化祭でタブを2つ開く人はまれ。前のタブで押すと「押したのに画面が変わらない」に見える。
- **直すならどこか**：`realtime.js` attachMember で前の socket に「別のタブで開きました」を送って止める、か、秘密を2本とも送る（`emitPrivate`）。

## 5. ゲームの途中で戻る（同じ memberId）

- **起きた事**：4本とも、入り直した返事のすぐあとに、今の場面（部屋の知らせ・文化祭の段階「遊ぶ」）と本人の秘密が届く（1.5秒以内・中身はいまの本人の秘密と同じ）。遊ぶ人のまま。
- **本番で困るか**：困らない。
- **直すならどこか**：なし。

## 6. サーバーを再起動した時

**2026-10-29 直した（くまくん「6だけ直して」）**：
- 参加者のスマホと TV：部屋が消えたら「いま部屋を作り直しています。係の人を待ってね」の画面へ（TV は TV のまま）。3秒ごとに `/api/fes/current` を見て、部屋ができたら /fes へ進む（「いまは部屋がありません」の画面も同じ見張りで自動で進む）
- 係の画面：つながり直したら見張り（fes:watch）を入れ直す。部屋が消えていたら「部屋が消えました。作り直してください」と大きく出し、作るボタン
- 運用メモ：「サーバーの再起動（push）は、遊んでいない時だけ。11/13 からは push しない」
- 検査：`tests/fes-screens.js`（再起動の6件）・`tests/fes-rejoin.js` 6。写真：`docs/監査_指示66の画像/fes-restart/`（git に入れない）

以下は直す前の記録：

- **起きた事**（サーバーは検査で作り直して確かめた。画面はコードを読んだ所見）：
  - 部屋はメモリにあるので消える。スマホ・TV は自動でつなぎ直して入り直そうとし、「部屋が無い」（room_not_found）。
  - **スマホと TV**：`rt.on('lost')` で ホーム（scr-v2-home）へもどり、「部屋がなくなっていました／**もう一度、部屋を作り直してください**」と出る。文化祭の参加者は部屋を作れないので、言い方が合わない。**TV もホームに落ちる**（係が TV で /fes?tv=1 を開き直すまで、TV は文化祭の画面にもどらない）。
  - **係の画面**：係は部屋の一員ではないので「部屋が無い」の知らせが来ない。**画面は古いまま止まる**（読み込み直すと「文化祭の部屋がありません」と作るボタン）。ログインは残る（セッションは SQLite）。
  - `/fes`（ポスターのQR）は、部屋が無い間は入口（「いまは文化祭の部屋がありません」）。係が作り直すと新しい部屋へ飛ぶ。新しい部屋はコードがちがうので、前の memberId では戻れず、**全員が新しい人として入り直す**（点・席・名前の「②」はなくなる）。
- **どうすれば戻れるか**：①係が係の画面を読み込み直して部屋を作る → ②TV で /fes?tv=1 を開き直す → ③参加者がポスターのQRを読み直す（またはホームから入り直す）。
- **本番で困るか**：困る（いちばん大きい）。文化祭の最中に落ちると、TV がホームに落ちて、参加者には「部屋を作り直して」と出る。係の画面は止まって見える。
- **直すならどこか**：
  - `public/index.html` の `rt.on('lost')`：文化祭の部屋だったら、ホームではなく /fes へ（TV は /fes?tv=1）。言い方も「係が部屋を作り直すまで待ってね」に。/fes は部屋が無い間は入口で待つので、作り直されたら読み直しで入れる（自動で読み直すなら、数秒ごとに /fes を見る）。
  - 係の画面：つなぎ直したら `fesOpenStaff()` を呼び直す（`rt-client.js` の connect に係の見張りの入り直しを足す）。
  - 部屋を消さない（ディスクに残す）のは大きな工事。運用（`docs/運用メモ.md`）で「再起動は遊んでいない時だけ」とするのが先。
