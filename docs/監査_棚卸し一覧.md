## 構造の要点（監査で確認した設計）

- **部屋のゲーム開始は `wolf:start` の1本道。** クライアントは `rtStartBtn` → `rt.startWolf()`、サーバーは成功後に `room:countdown` を全員へ放送し、`fx.js` の `countdown()` が3-2-1を出す。ゲームごとの分岐は無いので、新ゲームを `GAME_DRIVERS` に足せば自動的にカウントダウンも付く。
- **手渡しのカウントダウンは `scr-ready`（準備OK長押し）→ `scr-countdown` の1本道。** 全モードが通る。
- **退室の実処理は `rtLeaveRoom()`（クライアント）と `room:leave`（サーバー）に集約されている。** 画面ごとの「← 部屋を出る」ボタン7個と設定メニュー2経路は、すべて同じ関数を呼ぶ。
- **部屋ごと終わる方は `rtEndBtn` → `room:close` に集約。** 大画面の「部屋を閉じる」と設定→危険な操作→解散は `rtEndBtn.click()` へ委譲。
