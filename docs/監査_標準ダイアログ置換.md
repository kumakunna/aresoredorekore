## 種類の選び分け

| 種類 | いつ | 見た目 |
|---|---|---|
| `confirm` | 人の判断が要る。取り消せる | 主ボタン＋逃げ道 |
| `danger` | **取り返しがつかない**（全員が終わる／記録が消える） | 赤の縁・`warn` の振動・外側タップで閉じない |
| `info` | 知らせるだけ。判断は無い | ボタン1つ |
| `ask` | 文字か数字を入れてもらう（`prompt` の置換先） | 入力欄＋主ボタン |

### ※ 17（18712）について

`state.needPlayerSetup = confirm(...)` と、**戻り値をそのまま設定に入れている**。
いまの文言は「OK＝入力しなおす／キャンセル＝このメンバーのまま」で、
**ボタンの意味を本文で説明している**——ボタン自身が意味を持っていない形。
置換のついでに、2つのボタンにそれぞれの意味を持たせる
（「入力しなおす」「このまま続ける」）。どちらも取り消せるので `confirm`。

### 29（19269）を toast にする理由

「更新しました」は**判断が要らない知らせ**で、押して閉じる必要がない。
指示39 2-2 の使い分け（toast＝判断の要らない知らせ）に従う。
逆に「爆発しました」のような重い知らせは toast にしない。

## 着手前の再現（指示39 §1・4件）

直す前に、4件とも**実際に再現させて数値を取った**（指示39 §1の必須手順）。

### ① 文字サイズが効かない

`--font-scale` を 85% / 100% / 130% に動かして、375×667 で実測：

| | 85% | 100% | 130% |
|---|---|---|---|
| 見出し（`.scr-title`） | 24px | 24px | 24px |
| 本文（`.scr-sub`） | 13.3px | 13.3px | 13.3px |
| ボタン（`.btn`） | 16px | 16px | 16px |
| `.app` 自身 | 12.8px | 15px | 19.5px |

**原因**：`--font-scale` を使っている宣言は**1つだけ**（`.app` の `font-size:calc(15px * var(--font-scale))`）。
`font-size` の宣言は全部で**411個**あり、そのすべてが固定px。
`.app` の大きさを誰も継承していないので、設定を動かしても何も変わらない。

### ② 戻るが何回も要る

設定オーバーレイが**戻るの対象に入っていない**。

- 設定を開いたまま浮いている「戻る」を押すと、**設定は開いたまま、後ろの画面だけが動く**（`scr-mode` → `scr-shelf` を確認）
- **パネルの外を押しても閉じない**
- **ESC でも閉じない**
- ✕ は正しく丸ごと閉じる。開き直すと `root` から始まる（ここは正しい）

押しても閉じないので、閉じ方を探しながら何度も押すことになる。

### ③ ボタンが重なる

`#reactBar`（`position:fixed`・下から619〜657px・左から幅214px）が
`.wiz-foot`（下端639px・`padding-bottom:0`）と**約20px重なる**。
`#reactBar` は `RT_GAME_SCREEN_IDS` の全画面で出るので、**部屋の全ゲーム共通**。
背景の無い `btn-ghost` だと、文字が絵文字に潰されて読めない。

### ④ 設定がテーマに染まる → 実際は「読めない」

パネルの**背景はテーマに追従するのに、文字色は固定の濃い墨のまま**だった。

| テーマ | 文字 | 地 | コントラスト比 |
|---|---|---|---|
| 共通（テーマ無し） | #24272E | #EFE8D3 | **12.21 : 1** |
| `theme-auction` | #24272E | #2A1A1D | **1.11 : 1** |
| `theme-wolf` | #24272E | #161A29 | **1.16 : 1** |

本文に必要な最低線は 4.5:1（WCAG AA）。
**暗いテーマのカセットで遊んでいる間、設定を開くと中身がほぼ見えない。**
「世界観が混ざる」という見た目の問題ではなく、**使えなくなる**問題だった。
