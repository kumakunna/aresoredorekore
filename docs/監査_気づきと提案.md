- **[低] rtBombLiveが画面離脱でリセットされない**：`rtBombLive`は「解除中の画面を見ていた端末にだけ、

  次の爆弾ゲームの決着時に戻ってくると、見ていない試合の決着演出（クリア/爆発）が1回出る。
  演出が1回多いだけで情報漏れ・進行影響はなし。直すなら`rtBombLeaveScreen`に`rtBombLive = false;`を

- **[低・仕様判断] 部屋の参加人数に上限が無い**：`room:join`は人数チェックをしない（13人でも入れることを実機確認。

  描画・通信の負荷やUI崩れ（名簿・投票ボタンの数）があり得る。上限を設けるか（例：20人で「満員です」）、
