# 監査：状態と境界（第35弾B・型2の先回りリスト）

「境界をまたいで生き残る可能性のある状態変数」と「どの境界でリセットされるべきか」の一覧。
型2のバグ（リセット判断の誤り）を**実機で偶然踏むのではなく、一覧で先回りして確認する**ための正本。
網羅は目指さない——検証や実装で新しい状態に出会ったら1行足す運用（時間をかけすぎない）。

書式：`確認` 列は ✅=確認済み（日付） / 仕様=持ち越しが意図 / 未=部屋ゲーム等でこれから確認
