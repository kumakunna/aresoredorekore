## 3. 効かない設定・行き止まり（落とし穴21）

### (1) `titleFanfare` は一方通行で、しかも案内文が嘘 ◎

- 設定のどのページにも行が無い（`SET_*_ITEMS` にも `renderSetPrefs` にも無い）
- 唯一の窓口は獲得の重なりの中（`:3484 gotMuteToggle`）
- **一度OFFにすると重なりが二度と出ないので、二度とONに戻せない**（`:6873` で早期return）
- `:3482` に「設定の『見た目と演出』からいつでももどせます」と書いてあるが、**その行は存在しない**

**褒めることを止める設定が、片道になっている。** 大切なこと5に照らして直すべき。

### (2) 「このゲームの設定」に、何も起きない項目が出る（11モード）◎

`:20422` の除外が**古いフラグ**で書かれている：

    if(!m.wolf && !m.wolfRole && !m.bomb && !m.defuse && !m.quiz && !m.buzzer && !m.auction){

新しいカセットは別のフラグを名乗る（`quizKing` 4件・`auctionNew` 2件・`sugoroku` 5件＝**11モード**）。
この11モードは素通りして「⚡ハードモード」「🎙音声で判定」が出るが、
効き先は**あれそれどれこれ専用**（`state.hardMode` は `btnWrong`、`state.voiceDetect` は音声判定）。
説明文も「不正解で自動的に次のお題へ進みます」——**すごろくに「お題」は無い**（落とし穴2）。

### (3) 部屋なのに、端末ローカルのゲームが出る ◎

部屋の正本は `rtPickedGame()` / `rtPickedMode()`（`:10596` / `:10602`）。
**設定ハブはこの2つを一度も呼んでいない**（呼び出しは 10430・10657・10669・10737・11974・13592 で、すべて設定の外）。
設定が使うのは `gameById(currentGameId())` と `modeById(state.selectedModeId)`＝**その端末が最後に選んだもの**。

`rtPickedMode()` のコメント自身が同じ事故を戒めている（`:10607`）：
「modeById は知らないidだと先頭のモードを返す。…人狼の部屋にあれそれどれこれのルールが出る（大切なこと9）」
**設定だけがこの戒めの外にいる。**

### (4) そのほか（掃引の報告・抜き取りで確認）○

- `fxFlash` の JS 側の門（`:21283 flash:`）を読む行が `public/js/` に0件——CSSの1行だけが実効
- `fxShake` が止めない揺れが3系統（`.shake` `:190`、爆弾の `bombShake`）
- `seVolume` が爆弾の心拍に届かない（`sfxOut` のキャッシュ）
- `fontScale` の 95/100/105/110 は `--fs-*` が動かない（印は `<=92` と `>=115` の2つだけ）
- 設定の「部屋」ページはライブ更新されない（`rt.on('room')` から `renderSetRoom()` を呼んでいない）
