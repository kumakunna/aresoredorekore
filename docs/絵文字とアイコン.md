# 絵文字とアイコン（第32弾-B 第3部）

## なぜSVGにしたか

絵文字は **iOS・Android・PC で見た目がまったく違います。**
同じ部屋に iPhone と Android が混ざるのは普通のことで、その時、同じ「🐺」が
人によって違う絵に見えます。称号のアイコンは「集めたものを見せ合う」対象なので、
見え方がバラバラだと台無しになります。

## なぜ Twemoji か（判断の記録）

**Noto Color Emoji ではなく Twemoji を選びました。**

| | Twemoji | Noto Color Emoji |
|---|---|---|
| 形式 | 1絵文字＝1SVGファイル | フォント1本 |
| 使う分だけ置ける | ✅ できる | ❌ サブセット化のビルドが要る |
| 全部入りの重さ | 3,723ファイル（17MB） | 数MB〜10MB超 |
| ライセンス | CC-BY 4.0（**表記が必要**） | OFL（表記不要） |

このプロジェクトに**ビルド工程はありません**（`index.html` 1枚＋静的なJS）。
フォント方式だと、サブセット化のビルドを持ち込むか、数MBを丸ごと配ることになります。
Twemoji なら「使っている分だけファイルを置く」で済み、
指示の「起動速度を犠牲にしない」に**構造で**答えられます。

表記は設定の一番下に1行入れてあります（`#setCredit`）。

## いま置いてあるもの

```
public/img/emoji/     127ファイル・合計 356KB
```

全部入りの3,723ファイル（17MB）ではなく、**アプリで実際に使っている分だけ**です。

## どうやって当てているか

**727箇所の文字列を書き換えて回っていません。**
書き換えると必ずどこかを直し忘れますし、これから作る画面でも同じことを繰り返します。

代わりに、`#app` の中の変化を1つの `MutationObserver` で見て、
**画面に出た絵文字を、出たときに差し替えます**（`startEmojiSwap()`）。
これ1か所で、いま在る画面もこれから作る画面も自動でそろいます。

差し替えた形はこうです。

```html
<span class="emj" role="img" aria-label="🐺">
  <img src="img/emoji/1f43a.svg" alt="" decoding="async" onload="…">
  <span class="emj-txt">🐺</span>
</span>
```

### 決めごと3つ

1. **元の文字をDOMに残す。**
   画像が読めなかった時に文字で出ます。「絵文字が消えてボタンが空になる」
   という壊れ方をさせません。テストが `textContent` で見ているものも壊れません。

2. **既定は文字。画像が読めた時にだけ入れ替える。**
   逆（既定で画像・失敗したら文字）にすると、読み込みが始まらない環境で
   **何も出ない**状態になります。実際にそうなったので、この向きにしました。

3. **`loading="lazy"` は付けない。**
   2〜4KBのアイコンに遅延読み込みは向いておらず、環境によっては
   読み込み自体が始まりませんでした（実機確認で判明）。
   軽さは「置くファイルを使っている分だけに絞る」ことで達成しています。

## 絵文字にしないもの

`←` `→` `★` `✕` `✚` `©` は**絵文字ではなく記号**です。
UIの部品として文字で出ているのが正しく、Twemoji にも入っていません。

判定は2段構えです。

- 正規表現で、`©` `®` `→` などは **FE0F（絵文字にする印）が付いている時だけ**拾う
- さらに `public/js/emoji-list.js`（置いてあるSVGの一覧）と突き合わせ、
  **手元にファイルがあるものだけ**差し替える

この形なら、勝手に画像にすることも、読めない画像（壊れたアイコン）を出すこともありません。

## 絵文字を増やす時

1. `public/index.html` などで新しい絵文字を使う
2. Twemoji の SVG を `public/img/emoji/` に置く（ファイル名は下記の規則）
3. `node tools/gen-emoji-list.js` で一覧を作り直す

ファイル名は Twemoji の規則です。コードポイントを16進で `-` 区切り、
異体字セレクタ（FE0F）は落とす（キーキャップだけ残す）。
`public/js/emoji.js` の `fileName()` がその規則を持っています。

置き忘れは `tests/shelf.js`「アプリで使っている絵文字が、全部そろっている」が見つけます。
一覧とファイルの食い違いも、隣のテストが見張っています。
