# 遊んだ記録

**このアプリを、作った人以外が実際に遊んだ記録。**

テストは「壊れていないこと」しか見つけられない。
**遊んだ人が迷った所・盛り上がった所は、遊んだ人からしか出てこない。**
だから1回ごとに、下の型で1件ずつ足す。

## 記録の型（この5つを、毎回そろえる）

| 欄 | 何を書くか |
|---|---|
| **いつ・誰が** | 日付と、遊んだ人（作った人かどうかを必ず書く） |
| **何を** | ゲーム名・遊び方（手渡し／部屋）・人数 |
| **何が壊れたか** | 見たままを書く。原因の推測は書かない（推測は指示書側でやる） |
| **どこで迷ったか** | 壊れていないが、分からなかった所。**これが一番価値がある** |
| **盛り上がった所** | 無ければ「報告なし」と書く。**空欄にしない**——無かったことも情報 |

**直した先（指示番号）は、直した時に追記する。**
記録そのものは直さない——「その日、そう見えた」ことが記録の中身だから。

## 2026-09-10 ①

| 欄 | 中身 |
|---|---|
| **いつ・誰が** | 2026-09-10 / **くまくん以外の1人**（作った人ではない） |
| **何を** | クイズ解除（協力版）・**部屋**（1人1台） |
| **何が壊れたか** | 下の6件 |
| **どこで迷ったか** | **タイマー**（残り時間がどこにも出ていない）と**説明文**（ルールに書いてあるものが出てこない） |
| **盛り上がった所** | 報告なし |

### 何が壊れたか（6件）

1. **残り時間が最初から最後まで見えなかった。**ホストも参加者も `--:--`。
   設定を見たら「見たい時」になっていた（誰も選んだ覚えがない）。
   残り数秒で、突然赤い `00:06` が出た
2. **「爆発」の演出と「新しく手に入れた！解除班の証」が重なった。**
   半透明で重なり、どちらも読めない
3. **ルール文と実装が違う。**「コードをタップするとAIの説明文が出る」とあるが、
   タップした瞬間に3択が出た
4. **誰がどのコードを外したか分からない。**「ちがう！ライフが割れた」としか出ない
5. **参加者が開き直すと部屋に戻れない。**ログイン状態は残っているのに、トップに戻る
6. **答え合わせが見られない。**終わったあと、どれが何だったのかを振り返れない

→ 指示45 で 1〜6 を扱う。棚の縦のはみ出しも同時に見る（45-7）。

### 直した先（指示45で全件）

| # | 直したこと | 分かったこと |
|---|---|---|
| 1 | 仮面を「タップで見る」＋破線に。残り10秒は全テーマで仮面が外れ、理由を1度だけ言う | **既定は最初から `always` だった。**本番の配信物も手元と1バイト同じ。「赤い `00:06`」の正体はCSSの詳細度事故（落とし穴23）。あわせて**再戦の制限時間が 0:01 になる**事故も直した |
| 2 | 画面いっぱいの演出に順番待ちを作った（結果が先・褒めるが後） | 個別に「爆発の後に称号」とは書かない。演出の**性質**で決める |
| 3 | ルール文を実装に合わせた | **AIはもう呼んでいない**（第32弾-A-3-6）。言葉だけ4か所が3年ぶん取り残されていた。恒久対策 `tests/mode-rules.js` |
| 4 | 「だれが外したかを出す」を設定に足した（**既定OFF**） | 選んだ答えは配らない（次に挑む人の3択が2択になる） |
| 5 | 入口に「さっきの部屋にもどる」を出した | `hasOpenRoom()` が「進行役か」を返していたので、参加者は必ず素通りしていた |
| 6 | 答え合わせの画面を足した（手渡し・部屋の両方） | — |
| 棚 | 375×667 の 13〜67px を詰めた | **指示44の「375×812 で59px」は測定の側が間違っていた**（落とし穴28）。812 では1pxもはみ出していない |

証拠は `docs/監査_指示45の門.md`。

### この1件から分かった、いちばん大きいこと

**「遊んだ人が迷った所」は、テストからは絶対に出てこない。**
6件のうち、全テストが緑のまま本番に出ていたものが5件あった。
とくに②（ルール文）は**コードに「AIを呼ばない」と書いてある**のに、
言葉だけが3年残っていた——読む人がいなければ、言葉は腐ったまま動き続ける。

次に遊んでもらう時も、**「どこで迷ったか」を必ず聞く**こと。
壊れたものより、そちらの方が見つけにくい。
