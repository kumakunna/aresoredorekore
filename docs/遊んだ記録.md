# 遊んだ記録

**このアプリを、作った人以外が実際に遊んだ記録。**

テストは「壊れていないこと」しか見つけられない。
**遊んだ人が迷った所・盛り上がった所は、遊んだ人からしか出てこない。**
だから1回ごとに、下の型で1件ずつ足す。

## 記録の型（この5つを、毎回そろえる）

| 欄 | 何を書くか |
|---|---|
| **いつ・誰が** | 日付と、遊んだ人（作った人かどうかを必ず書く） |
| **何を** | ゲーム名・遊び方（手渡し／部屋）・人数 |
| **何が壊れたか** | 見たままを書く。原因の推測は書かない（推測は指示書側でやる） |
| **どこで迷ったか** | 壊れていないが、分からなかった所。**これが一番価値がある** |
| **盛り上がった所** | 無ければ「報告なし」と書く。**空欄にしない**——無かったことも情報 |

**直した先（指示番号）は、直した時に追記する。**
記録そのものは直さない——「その日、そう見えた」ことが記録の中身だから。

### 何が壊れたか（6件）

1. **残り時間が最初から最後まで見えなかった。**ホストも参加者も `--:--`。
   設定を見たら「見たい時」になっていた（誰も選んだ覚えがない）。
   残り数秒で、突然赤い `00:06` が出た
2. **「爆発」の演出と「新しく手に入れた！解除班の証」が重なった。**
   半透明で重なり、どちらも読めない
3. **ルール文と実装が違う。**「コードをタップするとAIの説明文が出る」とあるが、
   タップした瞬間に3択が出た
4. **誰がどのコードを外したか分からない。**「ちがう！ライフが割れた」としか出ない
5. **参加者が開き直すと部屋に戻れない。**ログイン状態は残っているのに、トップに戻る
6. **答え合わせが見られない。**終わったあと、どれが何だったのかを振り返れない

→ 指示45 で 1〜6 を扱う。棚の縦のはみ出しも同時に見る（45-7）。

### この1件から分かった、いちばん大きいこと

**「遊んだ人が迷った所」は、テストからは絶対に出てこない。**
6件のうち、全テストが緑のまま本番に出ていたものが5件あった。
とくに②（ルール文）は**コードに「AIを呼ばない」と書いてある**のに、
言葉だけが3年残っていた——読む人がいなければ、言葉は腐ったまま動き続ける。

次に遊んでもらう時も、**「どこで迷ったか」を必ず聞く**こと。
壊れたものより、そちらの方が見つけにくい。

## 進化じゃんけん（指示55-②・2026-09-20）— **実機は未検証**

機械では確かめられない、**実際に4人以上で座って遊んだ時にだけ分かること**。
次に人と遊ぶ時、この5つを見てください。

1. **進化の手応え。**段が1つ上がった瞬間、うれしいか。
   スマホは自分の段の札が下から跳ね上がり（0.4秒）、大画面では自分の名前が1段上の行へ移る。
   **「上がったことに気づかないまま次の回が始まる」なら、尺か見せ方が足りない。**
2. **10分は長いか短いか。**測った範囲では、通常版5段なら**7〜14回戦**で誰かが最終形に届く。
   1回戦はおよそ7秒（発表1.8＋手を出す3＋開く2.2）なので、**2〜3分で終わる見込み**。
   10分はほとんど効かない締め切りのはず。**短すぎて物足りないなら、段を6段にするか、
   持ち時間を5秒にする**（どちらも設定で変えられる）。
3. **「こんかいは おやすみ」をどう感じるか。**3人・5人など奇数の部屋では、
   **毎回1人が何もしない回**が出る（数学的に避けられない）。
   次の回で必ず当たるようにはしてあるが、**待っているあいだ退屈でないか**。
   退屈なら、待っている人の画面に「いま誰と誰が戦っているか」を出すことを考える
   （ただし**禁止事項**「1画面に相手と全員の段を同時に出す」に触れないこと）。
4. **「肩慣らし」が納得できるか。**自分だけ段が上がったあと、
   1つ下の人と当たる回は**勝っても負けても何も動かない**。
   これは「格上が格下に当たって落ちる」不公平を避けるための調整対戦だが、
   遊ぶ人から見て**「なんで動かないの？」にならないか**。
   なるなら、画面の言い方を変える（いまは「けっか」としか出していない）。
5. **AIと当たったことに気づくか。**相手が本当にいない時だけ、弱いAIが出る。
   名前はふつうの人と同じ形で出していて、大画面にも特別な見た目は作っていない。
   **ただし、公開しているランクと連敗数から逆算はできる**（負けたのに連敗が増えない）。
   **遊んでいる最中に気づかれるか**を見てください——気づかれるなら、
   AIの設計そのものを考え直す（設計メモ:239 が「入れるかどうか」を長く未決にしていた理由）。

## 初プレイのチュートリアル（指示57・2026-09-21）— **実機は未検証**

機械では**原理的に**確かめられないもの——
「初めての人が、これで本当に分かるか」は、初めての人にしか測れない。
次に**クイズ解除を遊んだことがない人**と遊ぶ時、この5つを見てください。

1. **最初に詰まった場所はどこか。**（これが一番大事な観点）
   台本は4手（コードをえらぶ → 3択 → ライフは共有 → ✕は再挑戦できる）。
   **台本が終わったあとに詰まったなら、手が足りていない。**
   逆に**3手目まで読まずに閉じたなら、多すぎる**。
   どちらも「何手目で閉じたか」ではなく、**そのあと何に迷ったか**を見てください。
2. **「はじめてですね」の問いかけを、どう受け取るか。**
   準備OKの前に1回だけ出る。**断る人がいるか**、いるならなぜか
   （「めんどう」なのか「自分は分かると思った」のか）。
   後者なら、聞かずに出して✕で閉じられる形の方がいいかもしれない。
3. **暗くなることを、じゃまだと感じないか。**
   62%暗くしている。**周りが見えなくなって不安になる人がいないか**。
   とくに部屋（1人1台）で、**他の人が何をしているか分からなくなる**のが不快でないか。
4. **光の輪に気づくか。**色に頼らず、明るさの差＋白い輪＋脈動（1.8秒周期）で示している。
   **明るい部屋・画面の明るさを下げている人**でも、どこを押すか分かるか。
   分からないなら、輪を太くするか、指のアイコンを足す。
5. **協力版で、時計が減ることを気にするか。**
   問いかけは**時計が走る前**に出しているが、台本そのものは盤が出てから動く
