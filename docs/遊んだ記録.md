# 遊んだ記録

**このアプリを、作った人以外が実際に遊んだ記録。**

テストは「壊れていないこと」しか見つけられない。
**遊んだ人が迷った所・盛り上がった所は、遊んだ人からしか出てこない。**
だから1回ごとに、下の型で1件ずつ足す。

## 記録の型（この5つを、毎回そろえる）

| 欄 | 何を書くか |
|---|---|
| **いつ・誰が** | 日付と、遊んだ人（作った人かどうかを必ず書く） |
| **何を** | ゲーム名・遊び方（手渡し／部屋）・人数 |
| **何が壊れたか** | 見たままを書く。原因の推測は書かない（推測は指示書側でやる） |
| **どこで迷ったか** | 壊れていないが、分からなかった所。**これが一番価値がある** |
| **盛り上がった所** | 無ければ「報告なし」と書く。**空欄にしない**——無かったことも情報 |

**直した先（指示番号）は、直した時に追記する。**
記録そのものは直さない——「その日、そう見えた」ことが記録の中身だから。

## 2026-09-10 ①

| 欄 | 中身 |
|---|---|
| **いつ・誰が** | 2026-09-10 / **くまくん以外の1人**（作った人ではない） |
| **何を** | クイズ解除（協力版）・**部屋**（1人1台） |
| **何が壊れたか** | 下の6件 |
| **どこで迷ったか** | **タイマー**（残り時間がどこにも出ていない）と**説明文**（ルールに書いてあるものが出てこない） |
| **盛り上がった所** | 報告なし |

### 何が壊れたか（6件）

1. **残り時間が最初から最後まで見えなかった。**ホストも参加者も `--:--`。
   設定を見たら「見たい時」になっていた（誰も選んだ覚えがない）。
   残り数秒で、突然赤い `00:06` が出た
2. **「爆発」の演出と「新しく手に入れた！解除班の証」が重なった。**
   半透明で重なり、どちらも読めない
3. **ルール文と実装が違う。**「コードをタップするとAIの説明文が出る」とあるが、
   タップした瞬間に3択が出た
4. **誰がどのコードを外したか分からない。**「ちがう！ライフが割れた」としか出ない
5. **参加者が開き直すと部屋に戻れない。**ログイン状態は残っているのに、トップに戻る
6. **答え合わせが見られない。**終わったあと、どれが何だったのかを振り返れない

→ 指示45 で 1〜6 を扱う。棚の縦のはみ出しも同時に見る（45-7）。
