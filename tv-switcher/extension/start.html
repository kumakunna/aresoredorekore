デスクトップの「あつまれ TV」から開いた Chrome でだけ「はじめる」を押せます。
この Chrome（ふだんの Chrome）は閉じてかまいません。

TV に「ログインしてください」が出ていたら、この Chrome で係のアカウントでログインしてから、もう一度「はじめる」を押してください。ログインの画面を開く

3音の出し先

Windows の音の出し先を、TV①（左）の HDMI にする（タスクバーのスピーカー → 出し先。SteelSeries Sonar を使う時は Sonar の出し先を）。あつまれ・動画・あそびまちの音は、全部ここから出ます。

4あそびまちの準備

「押すと始まります」は、この拡張機能が自分で押します。TV に「押すと始まります」が残っていた時だけ、下のボタンで両方の TV に出して、マウスで1回ずつ押してください。

TV① と TV② の「押すと始まります」を、1回ずつ押してください。
